# 소리 — 아직 안 들어온 자리

파일이 없으면 조용히 넘어갑니다. 화면은 그대로 돕니다.
넣으면 자동으로 납니다 (장면 에셋과 같은 규칙).

## 배경음  /audio/bgm/{이름}.mp3

| 이름 | 어디서 | 길이 | 결 |
|---|---|---|---|
| `hall` | 전 화면 | 60~90초 · 이어 붙는 고리 | 신비로운 결. 가야금·대금·아주 옅은 저음. 가락이 뚜렷하면 글을 읽는 데 방해가 됩니다 — **가락보다 결** |

★ 규격
- **-20 LUFS 안팎**. 이보다 크면 목소리를 덮습니다.
- **이음새가 없어야** 합니다. 끝과 처음이 이어지게 (장면 클립과 같은 규칙).
- 128kbps mono 면 충분합니다. **1MB 이하**로.
- 놀래키는 소리(타악 강타·급한 상승) 금지. 사주를 보는 사람은 이미 불안합니다.

## 목소리  /audio/voice/{이름}.mp3

도령이 하는 말 한 마디씩. 화면에 뜨는 그 문장과 **글자 그대로** 같아야
합니다 — 다르면 손님이 둘 중 무엇을 믿을지 몰라 합니다.

★ 결
- 삼십 대 남자, **낮고 느린데 처지지 않는** 소리. 판소리 아니고, 성우
  광고 톤도 아닙니다. **옆에 앉아 말하는** 거리.
- 하오체입니다. 「~하오」 「~소」 의 끝을 내려 맺습니다.
- 뜸을 들이되 1초를 넘기지 않습니다.

★ 규격
- 44.1kHz mono · 96~128kbps · 한 마디 **150KB 이하**
- 앞뒤 무음 0.15초 이하로 자릅니다
- 노이즈 게이트를 세게 걸지 마세요 — 숨소리가 사라지면 기계가 됩니다

★ 어디에 쓰이는지는 `tools/voice_sheet.py` 가 뽑아 줍니다.
