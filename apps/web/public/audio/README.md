# 소리 — 아직 안 들어온 자리

파일이 없으면 조용히 넘어갑니다. 화면은 그대로 돕니다.
넣으면 자동으로 납니다 (장면 에셋과 같은 규칙).

## 배경음  /audio/bgm/{이름}.mp3

| 이름 | 어디서 | 길이 | 결 |
|---|---|---|---|
| `hall` | 전 화면 | 60~90초 · 이어 붙는 고리 | 신비로운 결. 가야금·대금·아주 옅은 저음. 가락이 뚜렷하면 글을 읽는 데 방해가 됩니다 — **가락보다 결** |

★ 규격
- **-20 LUFS 안팎**. 이보다 크면 목소리를 덮습니다.
- 128kbps mono 면 충분합니다. **1MB 이하**로.
- 놀래키는 소리(타악 강타·급한 상승) 금지. 사주를 보는 사람은 이미 불안합니다.

### ★ 이음새 — 앱이 겹쳐 줍니다

전에는 「끝과 처음이 이어지게」라고만 적혀 있었습니다. 그건 **지킬 수
없는 부탁**입니다. 원본을 아무리 맞춰도 mp3 로 굽는 순간 인코더가 앞뒤에
0.05초쯤 되는 침묵을 붙이고, `<audio loop>` 는 되도는 자리를 브라우저가
잡아 주는 것이라 기기마다 늦습니다. 90초짜리면 한 시간에 마흔 번 도는데
그때마다 소리가 빕니다.

그래서 지금은 **앱이 손질합니다** (`apps/web/lib/sound.ts`).

```
받아서 푼다 → 앞뒤 무음을 깎는다 → 끝 1.5초를 첫 1.5초에 겹친다
            → 그 결과를 샘플 단위로 돌린다
```

덕분에 이음새를 못 맞춰 와도 이어집니다. 대신 **이 세 가지**를 지켜
주세요 — 지키면 겹치는 자리가 아예 안 들립니다.

```
· 앞뒤에 페이드를 걸지 마세요.
  꺼져 가는 소리를 첫머리에 겹치면 그 자리만 옴폭 들어갑니다.
  앱이 알아서 올리고 내립니다.

· 끝 1.5초는 첫 1.5초와 **포개집니다.**
  거기에 새 악구를 시작하거나 한 음을 길게 끌지 마세요.
  결만 남기면 됩니다.

· 최소 5초. 그보다 짧으면 겹칠 자리가 없어 그냥 붙입니다.
```

★ 겹치는 길이를 바꾸려면 `sound.ts` 의 `SEAM`. 가락이 뚜렷한 소리를
넣게 되면 짧게(0.6초쯤) 잡아야 두 겹으로 안 들립니다.

★ 영상 배경도 같은 사정입니다 — `tools/loop_seam.py` (`.\dev.ps1 loop`)

## 목소리  /audio/voice/{이름}.mp3

도령이 하는 말 한 마디씩. 화면에 뜨는 그 문장과 **글자 그대로** 같아야
합니다 — 다르면 손님이 둘 중 무엇을 믿을지 몰라 합니다.

★ 결
- 삼십 대 남자, **낮고 느린데 처지지 않는** 소리. 판소리 아니고, 성우
  광고 톤도 아닙니다. **옆에 앉아 말하는** 거리.
- 하오체입니다. 「~하오」 「~소」 의 끝을 내려 맺습니다.
- 뜸을 들이되 1초를 넘기지 않습니다.

★ 규격
- 44.1kHz mono · 96~128kbps · 한 마디 **150KB 이하**
- 앞뒤 무음 0.15초 이하로 자릅니다
- 노이즈 게이트를 세게 걸지 마세요 — 숨소리가 사라지면 기계가 됩니다

★ 한 번 나고 마는 소리라 고리를 만들지 않습니다. 배경음과 달리 앞뒤를
  깎는 손질도 안 합니다.

★ 어디에 쓰이는지는 `tools/voice_sheet.py` 가 뽑아 줍니다.
