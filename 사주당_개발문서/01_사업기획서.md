# 01 · 사업기획서

---

## 1. 한 줄 정의

> **맞히는 집이 아니라, 근거 대는 집.**
> 스무 명의 해석자가 같은 여덟 글자를 각자의 관점으로 읽는 사주 서비스.

---

## 2. 시장

### 규모

- 포스텔러 : 가입자 860만, 연매출 100억 이상, 누적투자 85억
- 점신 : 이용자 1,900만
- 이용자 성비 : **여성 압도적 다수** (업계 통설, 자체 검증 필요)

### 경쟁 구도

| 유형 | 사례 | 강점 | 약점 |
|---|---|---|---|
| 대형 플랫폼 | 포스텔러·점신 | 트래픽·데이터·만세력 정밀도 | 캐릭터성 약함, 몰입 없음 |
| 캐릭터형 | 귓속말사주 등 | 캐릭터=상품, 서사 진입 | 근거 없음, 병렬 나열, 리스크 큰 카피 |
| 상담 연결 | 각종 앱 | 실제 상담 | 인건비, 확장 어려움 |

### 우리가 들어갈 틈

경쟁사 후기에 반복해서 나오는 말 — **"근거를 대주니까 다르게 들렸다"**.
사용자는 이미 근거를 원하고 있는데, 대부분의 서비스가 시스템이 없어 못 합니다.

---

## 3. 포지셔닝

| | 경쟁사 | 성신당 |
|---|---|---|
| 주장 | "재회 시기를 맞힙니다" | "이 문장이 나온 근거는 이겁니다" |
| 증거 | 성공 후기 | 계산 과정 + 응답률 데이터 |
| 검증 | 불가능 | **가능** |
| 법적 리스크 | 높음 | 낮음 |
| 안 맞았을 때 | 환불·민원 | "구조를 말한 것이지 예언이 아니었다" |

### 절대 쓰지 않는 문구

```
과학적으로 입증된 / 통계학이라 정확하다 / 적중률 87%
연구로 검증된 / 반드시 / 확실히 / 틀림없이
```

상세는 11번 문서.

---

## 4. 제품 구조

### 4-1. 5개 엔진

| 엔진 | 입력 | 상품 |
|---|---|---|
| E1 Solo | 사주 1 | 성격·재물·직장·적성·건강 |
| E2 Scope | 사주 1 + 시간창 | 평생운·신년·월운·오늘 |
| E3 Dyad | 사주 2 | 궁합·재회·속마음·부부 |
| E4 Selection | 사주 + 날짜범위 | 결혼·이사·개업 택일 |
| E5 External | 사주 무관 | 타로·꿈해몽·성향검사 |

70여 개 SKU가 이 5개 엔진의 조합으로 나옵니다.

### 4-2. 캐릭터 20인 = 결합 축

| 축 | 추가 입력 | 인원 |
|---|---|---|
| A 무결합 | 없음 | 4 |
| B 검사 결합 | 성향 4글자 / 혈액형 / 심리테스트 | 3 |
| C 술수 결합 | 출생지 / 카드 / 사진 | 3 |
| D 관계 결합 | 상대 사주 | 4 |
| E 맥락 결합 | 현재 상황 자기입력 | 4 |
| F 정서 축 | 없음 (강조점 반전) | 2 |

**입력 데이터가 다를 때만 진짜 다른 상품**입니다. 상세는 07번 문서.

### 4-3. 연쇄 구조

```
훅(무료) → 무료 6단 → 결제 → 리포트 → 릴레이 → 다음 캐릭터 → …
```

릴레이는 **사주 조건이 추천을 결정**합니다. 광고가 아니라 진단이라 따라옵니다.

---

## 5. 수익 구조

### 가격 사다리

| 단계 | 상품 | 가격 |
|---|---|---|
| 무료 | 훅 + 무료 6단 + 오늘의 운세 + 꿈해몽 | 0 |
| 저가 | 재회·속마음·타로·적혈랑 | 3,900~6,900 |
| 중가 | 궁합·재물·직장·연애·적성 | 9,900~15,900 |
| 고가 | 평생운·결혼택일·은별무녀 | 19,900~29,900 |
| 구독 | 전 캐릭터 무제한 + 월간 세운 | 9,900/월 |

### 객단가 상승 장치

- **3단 티어** — 3,900 → 19,900 업그레이드 경로
- **번들** — 릴레이 상위 3인 묶음 30% 할인
- **인장첩** — 5개 다과상 / 10개 한정카드 / 20개 합본

### 리텐션 5층

| 주기 | 트리거 | 연 횟수 |
|---|---|---|
| 매일 | 일진 (원가 0) | 365 |
| 매달 | **절입일** 월운 갱신 | 12 |
| 연 2회 | 입춘 세운 · 생일 | 2 |
| 불규칙 | 분기점 예고 | 1~3 |
| 반기 | **회고 루프** | 2 |
| 10년 | 대운 전환 | 0.1 |

결제로 이어지는 건 연 5~8회로 봅니다.

## 6. 안전 장치 (매출보다 우선)

```
· 한 세션 릴레이 2명까지. 세 번째는 다음 날
· 거절한 캐릭터는 재권유 없음
· 무거운 리포트 뒤엔 무료 캐릭터(청동자)가 강제로 따라옴
· 재회는 같은 상대 7일 1회
· 하루 3회 이상 접속 시 도령이 직접 만류
```

**이 장치를 빼면 단기 매출은 오르고 서비스는 죽습니다.**
이 카테고리 앱이 사라지는 경로가 대부분 여기입니다.

## 7. 출시 로드맵

| 차수 | 캐릭터 | 검증할 것 |
|---|---|---|
| 1차 | 풍운도령 · 월하선녀 · 상단행수 | 무결합/관계/맥락 세 축 |
| 2차 | 은별무녀 · 삼거리노파 · 청동자 | 검사 축 + 정서 안전망 |
| 3차 | 패선생 · 홍매파 · 시계장이 | 재구매/객단가/희소자산 |
| 4차~ | 판매 데이터 기준 | 안 팔릴 캐릭터는 안 만듦 |

**노파는 청동자 없이 출시하지 않습니다.**

## 8. 핵심 지표

| 지표 | 목표 | 측정 |
|---|---|---|
| 훅 완주율 | 60%+ | 5단 전부 응답 |
| 무료→결제 전환 | 8%+ | 첫 결제 |
| 릴레이 전환 | 25%+ | 2번째 캐릭터 |
| 문장 중복률 | 15% 이하 | 임의 2인 비교 |
| 공감률 | 문장별 60%+ | statement_log |
| 30일 재방문 | 40%+ | — |

**문장 중복률**을 개발 중 상시 측정하세요. 이게 오르면 템플릿이 됩니다.
