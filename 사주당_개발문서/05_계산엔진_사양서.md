# 05 · 계산엔진 사양서

> **개발 1순위 문서.** 여기가 틀리면 다른 모든 것이 무의미합니다.
> 계산 정밀도가 이 서비스의 유일한 검증 가능한 자산입니다.

---

## 0. 전체 순서

```
입력 (년월일시분 · 성별 · 출생지)
  ↓
① 시각 보정        표준시 변천 → 서머타임 → 진태양시
  ↓
② 사주팔자 산출     년주 → 월주 → 일주 → 시주
  ↓
③ 오행 분포        천간 + 지지 본기 + 지장간 가중
  ↓
④ 신강약 판정      득령 · 득지 · 득세
  ↓
⑤ 용신 산출        억부법
  ↓
⑥ 십신 산출        일간 대비 음양·오행 관계
  ↓
⑦ 대운 산출        순행/역행 · 대운수
  ↓
⑧ 파생값          최강/최약 오행 · 흐름 · 일지 충합
```

## 1. 시각 보정 ★ 다른 앱이 대부분 안 하는 부분

### 1-1. 한국 표준시 변천

```python
def std_meridian(y, m, d) -> float:
    t = y*10000 + m*100 + d
    if t < 19120101: return 127.5   # 1908.4.1 ~ 1911.12.31
    if t < 19540321: return 135.0   # 1912.1.1  ~ 1954.3.20
    if t < 19610810: return 127.5   # 1954.3.21 ~ 1961.8.9
    return 135.0                    # 1961.8.10 ~
```

**1954~1961년생이 특히 중요합니다.** 이 구간을 135도로 계산하면 30분이 어긋납니다.

### 1-3. 진태양시 (경도 보정)

```python
correction_min = (birth_longitude - std_meridian) * 4
```

### 1-4. 적용 순서

```python
mins = hour*60 + minute
if is_dst: mins -= 60
mins += correction_min
if mins < 0:      mins += 1440; day_shift = -1
if mins >= 1440:  mins -= 1440; day_shift = +1
```

**날짜가 넘어가면 일주가 바뀝니다.** 반드시 처리하세요.

### 1-5. 균시차 (선택)

정밀도를 더 올리려면 균시차(±16분)를 추가합니다.
1차 출시에서는 생략 가능. 다만 자시 경계(23:00~01:00) 출생자는 영향을 받습니다.

### 2-3. 일주 — 율리우스 일수 ★ 가장 정확한 부분

```python
def jdn(y, m, d):
    a = (14 - m) // 12
    yy = y + 4800 - a
    mm = m + 12*a - 3
    return d + (153*mm+2)//5 + 365*yy + yy//4 - yy//100 + yy//400 - 32045

# 기준: 1900-01-01 = 甲戌
BASE = jdn(1900, 1, 1)
gan_idx = (jdn(y,m,d) - BASE + GAN.index("甲")) % 10
ji_idx  = (jdn(y,m,d) - BASE + JI.index("戌")) % 12
```

**검증** : 1900-01-01 甲戌 / 2000-01-01 戊午 / 2026-01-01 확인

### 2-4. 시주

## 6. 십신

```python
def ten_god(g, day_gan):
    e, me = element_of(g), element_of(day_gan)
    same = yin_yang(g) == yin_yang(day_gan)
    if e == me:                    return "비견" if same else "겁재"
    if generates(me) == e:         return "식신" if same else "상관"
    if controls(me)  == e:         return "편재" if same else "정재"
    if controls(e)   == me:        return "편관" if same else "정관"
    return "편인" if same else "정인"
```

집계 대상 : 천간 3개(일간 제외) + 지지 본기 4개 = **7개**
(시각 미상이면 천간 2 + 지지 본기 3 = 5개)

## 7. 대운

### 방향

```
양년생 남자 · 음년생 여자  → 순행
음년생 남자 · 양년생 여자  → 역행
```

### 대운수 (시작 나이)

```
순행 : 생일 → 다음 절입일까지의 일수 ÷ 3
역행 : 이전 절입일 → 생일까지의 일수 ÷ 3
(나머지 처리는 유파별. 반올림 방식을 확정할 것)
```

> **참조 구현체는 `(day % 3) + 3` 이라는 근사식을 씁니다. 반드시 교체하세요.**
