# 04 · 데이터베이스 설계서

PostgreSQL 15+ · 시간은 전부 `timestamptz`

---

## 1. ERD 요약

```
users ─┬─ charts ─┬─ reports ─── report_cuts
       │          ├─ hooks
       │          └─ statement_log      ★ 핵심 자산
       ├─ purchases
       ├─ seals                          인장 수집
       ├─ relay_log
       ├─ reviews
       └─ cooldowns

lenses (마스터)  products (마스터)  relay_rules (마스터)
```

## 2. 사용자

```sql
CREATE TABLE users (
  id            uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  nickname      text,                    -- 본명 아니어도 됨
  email         citext UNIQUE,
  created_at    timestamptz DEFAULT now(),
  last_seen_at  timestamptz,
  deleted_at    timestamptz              -- soft delete
);

-- 사용자별 하루 결제·릴레이 상한
CREATE TABLE daily_limits (
  user_id     uuid REFERENCES users(id),
  day         date,
  purchases   int DEFAULT 0,
  relays      int DEFAULT 0,
  visits      int DEFAULT 0,
  PRIMARY KEY (user_id, day)
);
```

## 3. 명식

```sql
CREATE TABLE charts (
  id            uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id       uuid REFERENCES users(id),
  owner_label   text,          -- '나' | '어머니' | '상대' 등
  birth_year    smallint NOT NULL,
  birth_month   smallint NOT NULL,
  birth_day     smallint NOT NULL,
  birth_hour    smallint,      -- NULL 이면 시각 미상
  birth_minute  smallint,
  hour_known    boolean NOT NULL DEFAULT false,   -- ★
  sex           char(1) NOT NULL,                 -- 'M' | 'F'
  birth_city    text,
  axis4         char(4),       -- 성향 4글자. NULL 허용
  features      jsonb NOT NULL,                   -- Feature Store 전체
  engine_ver    text NOT NULL,                    -- ★ 계산엔진 버전
  cache_key     text UNIQUE NOT NULL,
  created_at    timestamptz DEFAULT now()
);
CREATE INDEX ON charts (user_id);
CREATE INDEX ON charts USING gin (features);
```

> **`engine_ver` 이 중요합니다.** 만세력을 고치면 기존 명식의 결과가 달라집니다.
> 버전을 남겨두면 "언제 계산된 값인지" 추적하고 재계산 대상을 특정할 수 있습니다.

## 4. 마스터 — 렌즈 · 상품

```sql
CREATE TABLE lenses (
  id            text PRIMARY KEY,        -- 'pungun'
  name          text NOT NULL,
  hanja         text,
  school        text,
  group_name    text,                    -- 정통/관계/검사/술수/맥락/정서
  archetype     text,                    -- '차가운 미남'
  sex           char(1),
  you_word      text,                    -- 그대/자네/아저씨
  theme_color   text,
  combine_axis  text,                    -- NULL = 무결합
  focus         text[],
  avoid_domains int[],
  taboo         text[],                  -- ★ 절대 출력 금지
  handoff       jsonb,
  pages         int,
  price         int,
  released      boolean DEFAULT false,   -- 미출시는 실루엣
  sort_order    int
);

CREATE TABLE products (
  id             text PRIMARY KEY,
  name           text,
  engine         text,     -- solo|scope|dyad|selection|external
  scope          text,     -- lifetime|year|month|day|range
  lens_id        text REFERENCES lenses(id),
  domain_ids     int[],
  needs_partner  boolean DEFAULT false,
  needs_photo    boolean DEFAULT false,
  guardrail      text,     -- standard|reunion|health|child
  price          int,
  cooldown_days  int DEFAULT 0,          -- 재회 = 7
  active         boolean DEFAULT true
);
```

> 신상품 출시 = `INSERT` 한 줄. 코드 수정 없이 SKU를 늘립니다.

## 5. 훅 · 리포트

```sql
CREATE TABLE hooks (
  id          uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  chart_id    uuid REFERENCES charts(id),
  lens_id     text REFERENCES lenses(id),
  concern     text NOT NULL,             -- money|work|love|people|dir|health
  segments    jsonb NOT NULL,            -- 5단 + statement_id
  created_at  timestamptz DEFAULT now()
);

CREATE TABLE reports (
  id          uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  chart_id    uuid REFERENCES charts(id),
  lens_id     text REFERENCES lenses(id),
  product_id  text REFERENCES products(id),
  tier        text,                      -- free|one|all|sub
  concern     text,
  unlocked    text[],                    -- ['why'] | ['why','when','how']
  engine_ver  text,
  created_at  timestamptz DEFAULT now()
);

CREATE TABLE report_cuts (
  report_id    uuid REFERENCES reports(id) ON DELETE CASCADE,
  seq          int,
  kind         text,        -- hero|myeongsik|scene|domain|daeun|paywall|card
  statement_id text,
  body         jsonb,
  locked       boolean DEFAULT false,
  PRIMARY KEY (report_id, seq)
);
```

## 6. ★ statement_log — 가장 중요한 테이블

```sql
CREATE TABLE statement_log (
  id            bigserial PRIMARY KEY,
  statement_id  text NOT NULL,          -- 문장 뱅크 키
  chart_id      uuid REFERENCES charts(id),
  user_id       uuid REFERENCES users(id),
  lens_id       text,
  concern       text,
  stage         text,                   -- stab|myth|seq|gap|name
  -- 그 문장이 나온 조건 스냅샷
  day_gan       char(1),
  strength      text,
  top_ten_god   text,
  weak_el       char(1),
  strong_el     char(1),
  flow          text,
  axis4         char(4),
  -- 응답
  answer        smallint,               -- 1 그렇다 / 0 아니다 / NULL 무응답
  answered_at   timestamptz,
  shown_at      timestamptz DEFAULT now()
);
CREATE INDEX ON statement_log (statement_id, answer);
CREATE INDEX ON statement_log (chart_id);
CREATE INDEX ON statement_log (shown_at);
```

### 이걸로 무엇을 하나

```sql
-- 문장별 공감률 (화면 노출용)
SELECT statement_id,
       count(*) FILTER (WHERE answer = 1) AS hit,
       count(*) FILTER (WHERE answer IS NOT NULL) AS total,
       round(100.0 * count(*) FILTER (WHERE answer=1)
             / nullif(count(*) FILTER (WHERE answer IS NOT NULL),0), 1) AS rate
FROM statement_log
GROUP BY statement_id
HAVING count(*) FILTER (WHERE answer IS NOT NULL) >= 100;
```

**규칙**

- 응답 100건 미만이면 공감률을 **화면에 띄우지 않습니다** (거짓 광고)
- 공감률 60% 미만 문장은 뱅크에서 자동 내림
- 조건 스냅샷이 있어야 "어떤 사주에서 이 문장이 잘 먹히는지" 분석 가능

## 7. 릴레이 · 쿨다운

```sql
CREATE TABLE relay_rules (
  id          text PRIMARY KEY,
  lens_id     text REFERENCES lenses(id),
  priority    int NOT NULL,
  condition   jsonb NOT NULL,   -- {"field":"el.토","op":"<=","value":1.0}
  reason_tpl  text,
  quote_tpl   text,
  active      boolean DEFAULT true
);

CREATE TABLE relay_log (
  id          bigserial PRIMARY KEY,
  user_id     uuid,
  chart_id    uuid,
  rule_id     text,
  from_lens   text,
  to_lens     text,
  shown_at    timestamptz DEFAULT now(),
  clicked     boolean DEFAULT false,
  purchased   boolean DEFAULT false
);

CREATE TABLE cooldowns (
  user_id     uuid,
  kind        text,        -- 'reunion'
  target_hash text,        -- 상대 생년월일 해시
  until       timestamptz,
  PRIMARY KEY (user_id, kind, target_hash)
);
```

### 릴레이 규칙 튜닝

```sql
SELECT rule_id,
       count(*) AS shown,
       round(100.0*count(*) FILTER (WHERE clicked)/count(*),1) AS ctr,
       round(100.0*count(*) FILTER (WHERE purchased)/count(*),1) AS cvr
FROM relay_log GROUP BY rule_id ORDER BY cvr DESC;
```

전환율 낮은 규칙은 `priority` 를 내립니다.

## 8. 결제 · 인장 · 후기

```sql
CREATE TABLE purchases (
  id          uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id     uuid REFERENCES users(id),
  product_id  text REFERENCES products(id),
  chart_id    uuid,
  tier        text,
  amount      int,
  pg_tid      text,
  status      text,       -- pending|paid|refunded|failed
  paid_at     timestamptz,
  refunded_at timestamptz
);

CREATE TABLE seals (
  user_id    uuid REFERENCES users(id),
  lens_id    text REFERENCES lenses(id),
  got_at     timestamptz DEFAULT now(),
  PRIMARY KEY (user_id, lens_id)
);

CREATE TABLE reviews (
  id          uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id     uuid,
  report_id   uuid REFERENCES reports(id),
  lens_id     text,
  rating      smallint CHECK (rating BETWEEN 1 AND 5),
  body        text,
  verified    boolean DEFAULT false,   -- 결제 + 완독한 경우만 true
  visible     boolean DEFAULT true,
  created_at  timestamptz DEFAULT now()
);
```

> `verified=false` 후기는 **"결제 확인됨" 배지를 붙이지 않습니다.**
> 표시광고법상 후기 관련 분쟁이 가장 많이 나는 지점입니다.

## 9. 리텐션

```sql
CREATE TABLE notifications (
  id         bigserial PRIMARY KEY,
  user_id    uuid,
  kind       text,     -- daily|month|year|birthday|turning|lookback|new_lens
  payload    jsonb,
  send_at    timestamptz,
  sent_at    timestamptz,
  opened_at  timestamptz
);
CREATE INDEX ON notifications (user_id, send_at) WHERE sent_at IS NULL;
```

**하루 1건 제한** — 여러 트리거가 겹치면 우선순위 높은 것 하나만 발송.

### 회고 루프 조회

```sql
-- 6개월 전 그 사람이 받은 문장 꺼내기
SELECT statement_id, stage, shown_at
FROM statement_log
WHERE user_id = $1
  AND shown_at BETWEEN now() - interval '7 months'
                   AND now() - interval '5 months'
  AND answer = 1
ORDER BY random() LIMIT 1;
```

## 10. 개인정보 처리

| 컬럼 | 분류 | 처리 |
|---|---|---|
| `nickname` | 일반 | 본명 강제 안 함 |
| 생년월일시 | 일반 | 사주 계산 목적 |
| `sex` | 일반 | 대운 방향 산출에 필수 |
| `axis4` | 일반 | 선택 입력 |
| 얼굴 사진 | **생체인식정보** | **DB 저장 금지.** 메모리 처리 후 즉시 폐기 |
| 상대 생년월일 | 제3자 정보 | 이름·연락처 수집 금지 |

```sql
-- 탈퇴 시
UPDATE users SET deleted_at = now(),
                 nickname = NULL, email = NULL WHERE id = $1;
-- 30일 후 하드 삭제 배치
DELETE FROM charts WHERE user_id IN (
  SELECT id FROM users WHERE deleted_at < now() - interval '30 days');
```
