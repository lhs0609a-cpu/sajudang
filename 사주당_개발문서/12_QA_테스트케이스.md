## 1. 계산엔진 (최우선) ★

### TC-CAL-01 · 만세력 대조
```
방법  지인 20명 이상의 생년월일시를 기존 만세력 앱 2종과 대조
기준  사주팔자 8글자 100% 일치
```
**한 글자라도 틀리면 UI 작업 중단.**

### TC-CAL-02 · 경계 케이스

| 케이스 | 확인 |
|---|---|
| 2월 1~7일 출생 | 입춘 절입 **시각** 기준으로 년주 결정 |
| 각 절기 전후 ±2일 | 월주 정확 |
| 23:00~01:00 출생 | 자시 정책 일관 적용 |
| 1954~1961년생 | 표준시 127.5° 반영 |
| 서머타임 12구간 | −60분 반영 |
| 보정으로 날짜 넘어감 | 일주 이동 |
| 1900년 1월 1일 | 甲戌 |
| 2000년 1월 1일 | 戊午 |

### TC-CAL-03 · 시각 미상
```
입력  hour_known = false
확인  · 시주가 ◇◇ 로 표시
      · 오행 합계가 3주 기준
      · 십신 집계가 5개
      · 일지충 판정에 시지 미포함
      · 계산 패널에 "제외" 표기
실패  12시로 가정해 계산하면 즉시 반려
```

### TC-CAL-04 · 분포
```
방법  무작위 3,000명 생성
기준  일간 10종 각 8~12%
      십신 10종 각 6~14%
      흐름 5종 전부 5% 이상
      신강/중화/신약 극단 쏠림 없음
실패  어느 값이 0% → 도달 불가 분기 존재
```

## 2. 훅

### TC-HOOK-01 · 5단 진행
```
1. 각 단에서 그렇소/아니오 클릭
2. 먹 번짐 리플 재생
3. 버튼이 접히고 캐릭터 반응 표시
4. 0.66초 후 다음 단 자동 열림 + 스크롤
5. statement_log 에 기록
```

### TC-HOOK-02 · 어긋남 단
```
성향 입력 O + 불일치 O  → 2.5단 표시
성향 입력 O + 완전일치   → 2.5단 건너뜀
성향 입력 X             → 2.5단 건너뜀 (에러 없이)
```

### TC-HOOK-03 · 중복률 ★
```
방법  무작위 3,000명 × 무작위 고민 → 훅 전체 문장 비교
기준  중복률 15% 이하 (성향 입력 시)
현재  2.0%
```

## 3. 결제·티어

| 케이스 | 기대 |
|---|---|
| 무료 티어 클릭 | d0 무료 6단으로 진행 |
| one 결제 | "왜"만 해제, 언제/어떻게 잠금 + 업그레이드 CTA |
| all 결제 | 전부 해제 |
| 결제 후 d1 재방문 | "이미 치르셨소" 분기 |
| 결제 후 c4 재방문 | 잠긴 단어가 실제 값으로 해제 |
| 결제 실패 | d4, 재시도 가능 |

## 4. 릴레이·브레이크 ★

| ID | 케이스 | 기대 |
|---|---|---|
| B1 | 한 세션 3번째 릴레이 | 차단 + "내일 오시오" |
| B2 | "나중에" 누른 캐릭터 | 그 세션 재노출 없음 |
| B3 | 노파/연담 리포트 후 | 청동자 최상단 무료 노출 |
| B4 | 같은 상대 재회 재시도 | 7일 쿨다운 안내 |
| B5 | 하루 3회 접속 | 만류 메시지 |
| — | 추천 0개 | "오늘 만날 사람은 다 만났소" + 차/인장첩 |

**이 항목은 A/B 테스트 대상이 아닙니다.**

## 5. 콘텐츠 안전 ★

### TC-SAFE-01 · 금지어
```
방법  3,000명 × 전 캐릭터 × 전 고민 리포트 생성 → 필터 통과 여부
기준  위반 0건
```

### TC-SAFE-02 · 도메인 금지
```
자식운  불임·유산·요절 표현 0건
건강    질병명·처방·수술시기·수명 0건
재회    가능/불가 판정, 시점 확정 0건
노파    마지막 단락에 해법 100% 포함
```

### TC-SAFE-03 · 공감률 노출
```

```
