## 2. 색

```css
:root{
  /* 배경 — 자줏빛 검정 */
  --bg:#0C0A12;  --bg2:#151220;  --bg3:#1D1829;
  --line:#2E2740; --line2:#3A3150;

  /* 텍스트 */
  --paper:#F2ECE4;  --paper2:#B5ABBE;  --paper3:#726A80;

  /* 강조 */
  --gold:#E5B87A;   /* 로즈골드 — 기본 */
  --rose:#D98BA5;   --lav:#A896D4;  --teal:#7FC4BC;  --ember:#C9707A;

  /* 런타임 교체 — 캐릭터/일간 테마색 */
  --c:#E5B87A;
}
```

`--c` 는 JS로 바꿉니다. 성좌 원륜·입자·강조선이 전부 따라옵니다.

## 3. 타이포

```css
--serif:"Gowun Batang", serif;      /* 서사·대사·명식 */
--sans:"Noto Sans KR", sans-serif;  /* UI·본문 */
--mono:"IBM Plex Mono", monospace;  /* 근거·수치·라벨 */
```

| 용도 | 폰트 | 크기 |
|---|---|---|
| 찌르기 (0단) | serif | 22px (모바일 19) |
| 이름 (3단) | serif 700 | 27px |
| 대사 | serif | 17px |
| 나레이션 | serif | 16px |
| 본문 | sans 300 | 13.5px |
| 근거 칩 | mono | 8.5px |

**한자는 항상 serif.** sans로 쓰면 명식이 데이터처럼 보입니다.

## 4. 장면 공통 요소

모든 실내 장면에 들어가는 네 가지

```
빛기둥      위에서 내려오는 광선 · 은은한 명멸
부유 입자   금빛 알갱이가 천천히 상승
성좌 원륜   12방위 눈금 · 40초 1회전
주렴        금·홍·보라·청록 구슬발
```

여성 취향 요소

```
꽃(계절 4종) · 달 · 물 반사 · 청사초롱 · 검은 고양이
나비 · 반딧불 · 압화 · 다과 · 인장
```

**검은 고양이는 이 집의 마스코트**입니다. 담장·다과상·대운길·후기벽·배너에 등장.

## 6. 모션 원칙

```
· 카메라 동작은 한 클립에 하나만
· 얼굴은 눈 깜빡임 정도만
· 움직임 범위는 화면의 20% 이내
· 루프는 첫·끝 프레임 일치
```

## 7. 접근성

```css
@media (prefers-reduced-motion:reduce){
  *{animation:none !important; transition:none !important}
  .blk,.nr .l,.seq div span{opacity:1; transform:none}
  .pil{transform:none; opacity:1}
}
```

- 명도 대비 4.5:1 이상 (본문)
- 근거 칩(8.5px)은 보조 정보 — 필수 정보를 여기 두지 말 것
- 색만으로 정보를 전달하지 않음 (일간 강조는 색 + 테두리 + 발광)
