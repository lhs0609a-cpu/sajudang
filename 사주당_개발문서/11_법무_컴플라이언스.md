## 1. 표시광고법 — 절대 쓰지 않을 문구

| 금지 | 이유 |
|---|---|
| 과학적으로 입증된 | 그런 연구가 없음 |
| 사주는 통계학이라 정확하다 | 통계적 방법으로 만들어진 것이 아님 |
| 적중률 87% | 실증 근거 없는 성능 주장 |
| 연구로 검증된 | 근거 없음 |
| 반드시 / 확실히 / 틀림없이 | 결과 보장 |
| 재회 가능합니다 / 불가능합니다 | 판정 불가 |
| ○○년에 결혼합니다 | 시점 확정 |

### 근거

점성술 검증에서 가장 유명한 것은 1985년 Nature 게재 Carlson 의 이중맹검 연구로,
원 결론은 자연 점성술을 지지하지 않는다는 것이었습니다.
2009년 Ertel 의 재분석은 우연보다 나은 매칭을 보였다고 반박하나,
그 재분석조차 경험적으로 입증됐다고 보기엔 불충분하다고 명시합니다.

**가장 유리하게 해석해도 "입증됨"이 아니라 "부정 결론이 성립하기 어렵다" 수준**이며,
이는 점성술 얘기고 **사주 명리를 대규모로 검증한 연구는 사실상 없습니다.**

```
✅  절기 시각까지 계산합니다 (진태양시·서머타임·표준시 변천 보정)

✅  응답자 81%가 "그렇다"를 눌렀습니다      ← 데이터 100건 이상일 때만
✅  3,000년간 이어진 동양의 해석 체계입니다
✅  자기이해와 오락을 위한 서비스입니다
```

**"적중률"이 아니라 "공감률"** — 적중은 미래 검증이 필요하지만 공감은 응답 데이터입니다.

### 포지셔닝
> **"타고난 것과 지금의 당신이 어디서 갈라졌는지 봅니다"**

검증 가능하고, 유일하고, 공감이 제일 셉니다.

```

의학적·법률적·재무적 판단의 근거로 사용할 수 없으며,

응답률 수치는 실제 사용자 응답을 집계한 값이며, 예측 적중률이 아닙니다.
```

## 6. 콘텐츠 가드레일

### 도메인별 금지

| 도메인 | 금지 |
|---|---|
| 자식 | 불임·유산·요절 암시 |
| 건강 | 질병명 단정 · 처방 · 수술 시기 · 수명 |
| 재회 | 재회 가능/불가 판정 · 시점 확정 · 기다림 종용 · 상대 실명 |
| 재물 | 특정 종목·투자 시점 지시 |
| 전체 | 수명 · 자살 · 공포 조장 |

### 삼거리 노파 특칙
```
· 마지막 단락은 반드시 해법
· 인격·외모·가족 공격 금지
· 청동자(무료) 강제 연결
```

### 출력 후처리 필터

```python
BLOCK = [
  r"반드시.{0,10}(옵니다|됩니다|합니다)",
  r"(이혼|파혼|사망|요절)(합니다|한다|할 것)",
  r"(암|당뇨|우울증|공황|불임)",
  r"과학적으로|통계학|적중률\s*\d+%",
  r"\d+월까지 기다리",
  r"(수술|출산).{0,6}(날|택일)",
]
```
위반 시 재생성 1회 → 실패하면 안전 문장으로 대체 + 로그.
