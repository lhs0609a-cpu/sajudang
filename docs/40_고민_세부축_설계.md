# 40. 고민 세부축 설계 — 증상을 묻고 처방하는 집

> 2026-09-10. 손님이 짚은 것:
> **"정확하게 어떤 걸로 고민하는지 선택을 해야 정확한 진단을 내릴 거 아냐.
> 지금 병원이라고 치면 환자가 어떤 상태인지 물어보지도 않고 처방하는 거랑 똑같아."**
>
> `docs/20` 이 고친 것은 「여섯 칸에서 **셈**이 갈리는가」였습니다.
> 이 문서가 고치는 것은 「**묻고 나서** 셈이 갈리는가」입니다.

---

## 0. 무엇이 어긋났나 — 재 본 값

### 0-1. 물음이 처방 **뒤에** 있다

되묻는 자리(`TopicAsk`)는 이미 만들어져 있습니다. 그런데 **붙어 있는
자리가 하나뿐**입니다 —

```
apps/web/app/report/[id]/page.tsx:700   ← 값을 치른 뒤 본문(c2)
```

무료 구간(`/pay?step=d0`)에는 안 붙어 있습니다. 즉 지금 차례는 이렇습니다.

```
고민 고르기 → 훅 다섯 마디 → 무료 리포트 → 목패 → 값 → 그제야 「어디가 아프오?」
```

**증상을 묻는 자리가 처방 뒤에 있습니다.** 손님 말 그대로입니다.

### 0-2. 사랑은 아예 안 묻는다

`seed/topic.json` 의 `ASK` 에 다섯 칸만 있습니다.

| 고민 | 되묻는가 | 붙은 캐릭터 수 |
|---|---|---|
| money | ○ (둘) | 2 |
| work | ○ | 5 |
| people | ○ | 5 |
| dir | ○ | 5 |
| health | ○ | 3 |
| **love** | **✕** | **5** |

사랑에 **다섯이 몰려 있는데 되묻는 물음이 없습니다.** 짝사랑 온 사람,
결혼 시기 물으러 온 사람, 헤어진 사람이 같은 다섯 칸을 받습니다.

### 0-3. 캐릭터가 덮는 주제 스물이 여섯 칸으로 눌린다

```
궁합·밀당 적혈랑   결혼·혼인시기 홍매파   재회·이별 연담     사랑·인연 월하선녀
다툼·시비 화경     시험·자격 훈장         이직시기 시계장이   진로·적성 청암거사
해외·이주 서역     날잡기·개업 일관       돈·장사 상단행수    관상 면상선생
몸·잠 약초의원     갈림길 삼거리노파       신살·꿈 몽화        성격 은별무녀
```

주제는 스무 갈래인데 **셈을 가르는 축은 여섯**입니다. 훈장(시험)은
「일」로, 일관(택일)은 「방향」과 「돈」에 걸쳐 눌립니다.

## 1. 원칙 — 이것부터 어기지 않는다

### 1-1. 세부는 **낱말이 아니라 축**을 바꾼다

`docs/20` 의 규칙 그대로입니다. 「짝사랑」을 고르면 문장만 바뀌는 것이
아니라 **세는 자리가 바뀌어야** 합니다. 안 그러면 고른 뜻이 없습니다.

    안 됨   짝사랑 → 「짝사랑이시군요」 (낱말만 바뀜)
    맞음    짝사랑 → 재성/관성이 **천간에 드러났는가**를 센다
                    (마음이 밖으로 나가는 자리라 투출을 본다)

### 1-2. 못 세는 것은 **안 묻는다**

물어 놓고 못 세면 그건 받아 내는 것입니다. 이 집이 셀 수 있는 것은
`engine/features.Features` 에 든 것뿐입니다 —

```
ten_gods(10) · jae gwan sik inn bi · strength · yongsin · weak_els · strong_el
palaces(년월일시 · 누구 자리 · 나이 구간 · 십신)   ← docs/14 §6
sinsal  cheoneul taegeuk munchang geumyeo amrok yangin
        dohwa yeokma hwagae gwaegang baekho gongmang wonjin
gongmang · ilji_hap · ilji_chung · deuk_ji · deuk_ryeong
daeun[] (칸마다 start_age · ten_god) · daeun_now · daeun_started
```

★ **홍염(紅艶)은 이 집에 없습니다.** 사랑 갈래를 짜면서 쓰고 싶어지는
자리인데 `seed/sinsal.json` 에 없습니다. 없는 것으로 세면 그건 계산이
아니라 지어내기입니다 (절대 규칙 1). 도화(`dohwa`)만 씁니다.

★ **세운(그 해 간지)도 아직 없습니다.** `f.saju_year` 는 태어난 해이지
올해가 아닙니다. §4 에서 따로 다룹니다.

### 1-3. 앞에서 묻지 않는다

2026-09-10 에 잰 값 — 1만 명 중 **83%가 훅을 보기도 전에** 나갔고,
그 자리를 닫는 데 이번 판을 다 썼습니다. 진입 본길은 여섯 화면이고
`a5` 는 고르기 **한 번**입니다.

    여기에 두 번째 물음을 얹으면 방금 되찾은 사람을 도로 내보냅니다.

세부는 **훅을 다 들은 뒤**에 묻습니다. 그때는 손님이 이미 자기 얘기를
들었고, 되묻는 것이 서식이 아니라 **더 보려는 동작**이 됩니다.

### 1-4. 판정하지 않는다 (docs/11)

    재회 갈래   「이루어지오/아니오」 금지 · 시점 확정 금지 · 기다림 종용 금지
    몸 갈래     질병명 금지 · 수명 금지
    사랑 갈래   이혼 단정 금지
    돈 갈래     투자 시점 지시 금지

세부 갈래는 **세고 맞대 보기만** 합니다. 「겹치오」 / 「어긋나오」 두
꼴이고, 어긋날 때는 나무라지 않고 **그래서 더 힘이 들었다**고 말합니다.
지금 `ASK.money` 의 `hit`/`miss` 가 이미 그 꼴입니다 — 그대로 씁니다.

### 1-5. 「모르겠소」를 반드시 둔다

그렇소·아니오 둘만 두면 애매한 사람이 거짓 답을 눌러 공감률이
오염됩니다 (CLAUDE.md). `topic.ask_cut` 이 이미 「모르겠소」를
**노출로만** 셉니다. 새 갈래도 같습니다.

## 2. 물음이 서는 자리 — 차례를 고친다

```
지금
  a5 고민 → a7 훅 → d0 무료 → d1 목패 → 값 → c2 본문에서 「어디가 아프오?」

고침
  a5 고민 → a7 훅 → d0 무료 ─┬─ 「어디가 아프오?」  ← 여기로 올린다
                              └─ 답하면 무료 컷 하나가 그 자리 셈으로 바뀐다
                            → d1 목패 → 값 → c2 본문 (답이 그대로 실린다)
```

### 왜 d0 인가

| 자리 | 진입 비용 | 손님 상태 | 답할 까닭 |
|---|---|---|---|
| a5 (고민 고를 때) | **큼** — 이탈 구간 | 아직 아무것도 못 받음 | 없음 (서식) |
| a7 (훅 도중) | 중간 | 다섯 마디 답하는 중 | 흐름이 끊김 |
| **d0 (무료 끝)** | **없음** | 자기 얘기를 막 들음 | **더 정확해진다** |
| c2 (값 치른 뒤) | 없음 | 이미 삼 | **늦음** ← 지금 |

d0 에서 물으면 **답이 무료 구간 안에서 값을 합니다.** 그게 「묻고
처방한다」는 말의 뜻이고, 동시에 목패 앞에서 가장 센 설득이 됩니다 —
손님이 직접 적은 것과 여덟 글자가 겹쳤을 때요.

### 붙이는 법

`build_report` 는 이미 tier 와 무관하게 `asks` 를 냅니다
(`report.py:1730`). 화면만 붙이면 됩니다.

```
apps/web/app/pay/page.tsx   d0 갈래에 <TopicAsk spec={free.asks} …/>
                            답한 것은 extras.topic 으로 다시 무료 리포트를 부른다
```

★ 컷 하나가 **더 생기는 게 아니라 갈아 끼워집니다.** 무료 구간이
길어지면 안 됩니다 (지금 501초). `topic.ask_cut` 이 낸 컷을 `why`
자리에 겹쳐 놓습니다.

## 3. 여섯 칸의 세부 갈래

각 갈래는 **무엇을 세는가**로만 정의합니다. 문장은 `seed/topic.json`
의 `say.{key}.hit` / `say.{key}.miss` 에 씁니다.

### 3-1. 사랑 (love) — 지금 비어 있는 칸

```json
"love": {
  "title": "지금 사랑이 선 자리",
  "lead": "지금 자리를",
  "q": "지금 사랑은 어느 자리에 있소?",
  "options": {
    "alone":  "마음만 있소 (짝사랑·시작 전)",
    "dating": "만나는 중이오",
    "broke":  "끝났거나 끝나는 중이오",
    "long":   "오래갈지가 궁금하오 (결혼·장래)"
  }
}
```

| 갈래 | 세는 자리 | 판정 (`_ask_hit`) | 왜 이 자리인가 |
|---|---|---|---|
| **alone** 짝사랑 | 짝 글자의 **투출** + 도화 | 남: `정재·편재`가 천간에 있는가 / 여: `정관·편관`이 천간에 있는가 · 또는 `dohwa` | 마음이 밖으로 나가는 자리라 **드러났는지**를 보오. 지지에만 숨었으면 안에서만 도오 |
| **dating** 만나는 중 | 배우자궁(일지)의 **합·충** | `ilji_hap` 이 있는가 (합) · `ilji_chung` 이 아닌가 | 곁자리가 묶였는지 부딪히는지. 지금 붙어 있는 관계의 결 |
| **broke** 끝남·정리 | 일지 **충·형** · 배우자궁 **공망** · 원진 | `ilji_chung` · `gongmang` 이 일주에 걸리는가 · `wonjin` | 끊기는 자리를 봅니다. **끊긴다고 말하지 않고** 끊는 데 힘이 드는 자리인지만 |
| **long** 오래가기 | 짝 글자의 **뿌리(통근)** + 대운에 그 십신 칸이 있는가 | 남: `jae>=1` 이고 지지에 통근 / 여: `gwan>=1` 이고 통근 · `daeun[]` 에 해당 ten_god 칸 | 오래가는 것은 개수가 아니라 **뿌리**요. 대운은 때만 세고 **결과를 말하지 않소** |

★ **broke 갈래의 금지선.** 「끝나오/안 끝나오」, 「돌아오오/안 돌아오오」
는 절대 안 됩니다. 낼 수 있는 말은 「끊는 데 힘이 드는 자리요」
「그 힘이 미워하는 데로 새면 오래 걸리오」 까지입니다 (`SITUATION.part`
가 이미 그 꼴로 쓰여 있습니다 — 같은 결로).

### 3-2. 일 (work) — 있으나 얕다

지금 넷: 조직 안 / 혼자 / 준비 중 / 쉬는 중. **시험이 「준비 중」에
뭉개져 있습니다.** 훈장(시험·공부·자격증)이 붙어 있는데도요.

```
고침   조직 안 · 내 일 벌이는 중 · 시험·자격 준비 · 옮기는 중 · 쉬는 중
```

| 갈래 | 세는 자리 | 판정 |
|---|---|---|
| org 조직 | 관성 | `gwan >= 1` |
| **biz 내 일** (새로) | **식상생재** — 만든 것이 값이 되는 다리 | `sik >= 1 and jae >= 1` |
| **exam 시험** (새로) | 인성 + 문창귀인 | `inn >= 2` 또는 `munchang` |
| **move 옮김** (새로) | 관성의 충·역마 | `yeokma` 또는 관성 자리가 충 |
| rest 쉬는 중 | 식상 과다 · 신약 | `sik >= 3 or strength == "신약"` |

### 3-3. 돈 (money) — 이미 둘, 그대로 둔다

「어디서 오오」 + 「어디서 새오」 두 물음이 이미 있고 판정도 붙어
있습니다. **손대지 않습니다.**

### 3-4. 사람 (people) · 방향 (dir) · 몸 (health)

셋 다 물음이 있습니다. 다만 **방향**은 캐릭터가 다섯(해외·택일·
갈림길·오늘운·채울 것)인데 물음이 하나라 얕습니다. 2차로 미룹니다.

## 4. 세운 — 올해. 시간 축의 구멍을 메운다

### 4-1. 무엇이 비어 있었나

```
일진 g1   하루     있음
세운       한 해    ★ 없었음
대운 c3   십 년    있음
```

`terms` 에 「세운 = 그 해의 기운」이 정의돼 있고 근거 줄에도 찍히는데
**세우는 자리가 없었습니다.** `f.saju_year` 는 태어난 해입니다.

### 4-2. 고치면서 찾은 진짜 버그

리포트가 올해를 이렇게 세고 있었습니다 —

```python
this_year = f.saju_year + f.age
```

`age` 는 **양력 해**로 세고 `saju_year` 는 **입춘**으로 세는데 둘을
더했습니다. 자가 다른 둘을 더한 것이오. 그래서 —

```
1995-01-10 생 · 2026년 9월에 열람
  saju_year 1994(입춘 앞이라 앞 해) + 나이 31 = 2025    ← 한 해 어긋남
  화면에 「2025년은 乙巳」 라고 나갔습니다. 올해는 丙午인데요.
```

**입춘 앞에 태어난 사람 전원**이 틀린 세운을 받고 있었습니다.

### 4-3. 고친 것

`features` 에 세 칸을 답니다. 해가 바뀌는 자리는 설이 아니라 입춘이라
`solar_terms.saju_year_of` 를 그대로 씁니다 — 명식의 년주를 세우는 그
식이오. 두 벌로 두면 한쪽만 고쳤을 때 어긋납니다.

```python
year_num      입춘으로 가른 올해        2026
year_gz       올해의 두 글자            丙午
year_ten_god  그 해 천간이 나에게 뭔가   겁재
```

    2027-01-20  →  2026 · 丙午   (입춘 전이라 앞 해)
    2027-02-10  →  2027 · 丁未

★ **그 해에 무슨 일이 생긴다고 말하지 않습니다.** 바뀌는 때만 셉니다.
  이건 기존 규칙 그대로입니다.

## 5. 매매·부동산 — 금지선을 넓히고 나서 연다

### 5-1. 왜 조심하나

`docs/11` 이 **투자 시점 지시**를 금합니다. 그런데 `seed/guard.json` 의
표는 주식·코인·투자만 잡고 있었습니다 — **집·땅은 그물 밖**이었습니다.
부동산을 열면서 브레이크를 먼저 넓혔습니다.

```
(부동산|아파트|매매|전세|월세|분양|상가|토지)\s*[을를]?\s*.{0,8}
  (사시오|파시오|사라|팔라|사야|팔아야|들어가시오|지금이\s*때|올해가\s*좋|내년에\s*파)
(집|땅)\s*[을를]\s*.{0,6}(사시오|파시오|사야\s*하|팔아야\s*하)
```

★ **낱말만으로 안 잡습니다.** 이 집이 스스로를 「이 집」이라 부르고
「집에 늦게 들어가는 날」 같은 살림의 말이 글에 늘 있습니다. **시키는
꼴**일 때만 잡습니다. (「암록·청암거사」가 통째로 지워지던 사고와 같은
자리 — `guard.json` 의 `_note`)

    통과   이 집은 언제 사고팔지는 말하지 않소
    통과   집에 늦게 들어가는 날이 잦았을 것이오
    막힘   올해 부동산을 사시오 · 아파트를 팔아야 하오 · 땅을 사야 하오

### 5-2. 무엇을 읽는가

돈 물음의 첫 갈래에 **「집·땅에서」** 를 답니다. 세는 것은 둘입니다.

| 세는 자리 | 무엇인가 |
|---|---|
| **재고(財庫)** | 재성 기운이 **갈무리되는 지지**. `GO_JI` 확정표 — 木未·火戌·土辰·金丑·水辰 |
| **흙의 개수** | 겉으로 보이는 토가 셋 이상인가 (`visible(f,"토")`) |

```
겹침    담기는 자리가 있소 — 흐르는 돈보다 묵히는 돈이 남는 쪽이오
어긋남  담기는 자리가 없소. 못 한다는 말이 아니라, 묵혀 두는 동안
        그대 마음이 남보다 더 든다는 말이오
```

### 5-3. 안 하는 것

    ✕ 언제 사고팔지          ✕ 오를지 내릴지
    ✕ 이 집이 맞는 집인지     ✕ 몇 년도가 좋은지

마지막 줄에 그 약속을 **글로 박아 둡니다** —

> 이 집은 **언제 사고팔지는 말하지 않소** — 여덟 글자가 가리키는 것은
> 때가 아니라 **자리**요.

## 5-B. 주식·코인 — 「무엇이 오를까」는 답할 수 없고, 「그대 그릇」은 답할 수 있다

### 왜 이게 어려운 자리인가

관심이 가장 많은 자리인데 **금지선이 가장 가깝습니다.** 손님이 듣고
싶어 하는 말(「오를까요」)이 정확히 못 하는 말입니다.

그렇다고 안 여는 것도 답이 아닙니다. 사주가 그 자리에서 **진짜로 셀 수
있는 것**이 따로 있기 때문입니다 —

    못 함    무엇이 오를지 · 언제 사고팔지 · 얼마를 넣을지 · 어느 종목인지
    할 수 있음   **크게 걸었을 때 그대가 버티는 사람인가**

이건 예언이 아니라 **그릇**입니다. 명리의 본령이고, 금지선을 안 넘습니다.

### 세는 자리 — 이미 다 있었습니다

| 자리 | 무엇을 말하는가 | 어디에 |
|---|---|---|
| **편재** | 굴리는 재물의 자리가 있는가 | `ten_gods["편재"]` |
| **재다신약** | 큰 돈이 들어와도 **감당 못 하는** 짜임인가 | `pattern` 짜임 |
| **군겁쟁재** | 나눌 입이 여럿 — 벌어도 나가는가 | `pattern` 짜임 · `f.bi` |
| **식상생재** | 만든 것이 값으로 건너가는 다리 | `f.sik` · `f.jae` |

넷 다 엔진에 있었습니다. **물어보는 자리만 없었습니다.**

### 브레이크를 먼저 넓혔습니다 — 여섯 개가 다 새고 있었습니다

열기 전에 재 봤습니다. 표는 「주식을 **사시오/파시오/시기**」만 잡고
있었는데, 금지선을 넘는 말은 시키는 말뿐이 아닙니다.

```
새던 말   코인이 오르오 · 주식이 크게 오를 것이오 · 비트코인은 내년에 떨어지오
          이 종목이 좋소 · 투자로 수익이 나오 · 올해는 주식이 좋소
```

★ **어미를 「오르」로만 적으면 「오를」이 샙니다.** 오+르 와 오+를 은
  다른 글자요. 줄표(—)와 출처 묶음표에서 한 번씩 겪은 것과 같은 자리입니다.

지금은 **열하나 다 막히고**, 막히면 안 되는 다섯(「이 집은 무엇이
오를지는 모르오」 · 「해가 오르는 쪽으로 힘이 흐르오」 따위)은 다
통과합니다.

### 무엇을 내는가

돈 물음 첫 갈래에 **「굴리는 것 · 주식·코인」** 을 답니다. 적중 **49.3%**.

```
겹침    편재가 있소 — 굴리는 자리요. 다만 이 집은 무엇이 오를지는
        모르오. 그건 사주가 아니오. 셀 수 있는 것은 그대가 크게
        걸었을 때 버티는가요 — 지금 그대는 중화이고, 나눌 입인
        비겁을 하나 세었소.

어긋남  편재가 없소. 하지 말라는 말이 아니오 — 크게 굴리는 판이
        그대에게는 늘 남보다 무겁다는 말이오. 굴리는 크기보다
        버티는 기간을 먼저 정해 두는 편이 맞소.
```

마지막 줄은 돈 물음 전체에 붙습니다 —

> 이 집은 **언제 사고팔지는 말하지 않소** — 여덟 글자가 가리키는 것은
> 때가 아니라 **자리**요.

★ 「하지 마시오」 도 안 합니다. 그것도 투자 지시입니다. **버티는
  기간을 먼저 정하라**까지가 이 집이 할 수 있는 말이오.

## 9. 답이 **처방까지** 흘러가게 — 여섯 고민 전부

### 9-1. 무엇이 어긋났나

되묻는 자리를 무료 구간으로 올리고 갈래를 늘렸는데, 답이 처방에
**거의 안 닿고 있었습니다.** 사랑에서 갈래를 바꿔 유료 전부(31컷)를
견줬습니다 —

```
혼자 마음만 ↔ 만나는 중    달라진 컷 1개 (topic_ask)
혼자 마음만 ↔ 끝나는 중    달라진 컷 1개 (topic_ask)
혼자 마음만 ↔ 오래가는 일  달라진 컷 1개 (topic_ask)
```

짝사랑이든 이별이든 **나머지 30컷이 글자 하나 안 달랐습니다.** 답은
「겹치오/어긋나오」 한 문장만 고르고 끝났습니다.

### 9-2. 여덟 글자가 모자란 게 아니었다

사랑에서 이미 셀 수 있는 사실 열 가지(짝 글자 수 · 투출 · 뿌리 · 도화 ·
일지 합 · 일지 충 · 짝 공망 · 원진 · 지금 대운 · 올해 세운)로 2,000명을
가르면 —

```
서로 다른 조합  353가지 · 실효 약 177갈래(7.5비트) · 가장 흔한 조합 4.0%
```

물음은 그중 **8갈래**(갈래 4 × 겹침/어긋남)만 쓰고 있었습니다. 엔진은
가를 줄 알았고, **물음이 셈에 안 꽂혀 있었습니다.**

### 9-3. 「많이 물을수록 정교하다」는 반만 맞다

물음이 정교함을 더하는 것은 **그 답이 세는 자리를 바꿀 때뿐**입니다.
여덟 글자는 고정이고, 손님의 답은 그중 **어느 사실을 볼지를 고를** 뿐입니다.

    「누가 먼저 헤어지자고 했소?」 → 여덟 글자는 이걸 모릅니다.
    답이 무엇이든 세는 사실이 안 바뀝니다. 물으면 정교해 보이지만
    같은 말이 나옵니다 — 거짓 정밀도요.

그래서 잣대는 **물음의 개수가 아니라 답 하나가 몇 컷을 바꾸는가**입니다.
그 너머는 캐묻기이고, 캐물을수록 이탈이 늡니다(§1-3).

### 9-4. 지은 것 — 답이 셋으로 흘러간다

새로 세지 않습니다. 답은 **어느 칸·어느 짜임을 먼저 볼지**를 고릅니다.
조건이 안 맞는 것은 여전히 안 섭니다. 답 안 한 사람은 **예전과 같은 글**을
받습니다.

| 흘러가는 자리 | 무엇이 바뀌나 |
|---|---|
| **저울** `topic.scale(f, c, sub)` | 답이 가리키는 칸을 **소리 나는 칸끼리** 앞에 |
| **짜임** `pattern.read(..., focus=)` | 답이 가리키는 짜임을 먼저 봄 (안정 정렬 · 나머지는 원래 차례) |
| **때** `topic.turn(f, c, sub)` | 답이 가리키는 자리를 **올해 세운**이 건드리는가 한 줄 |

표는 `seed/topic.json` 의 `SUB_FOCUS` 한 곳입니다 — 여섯 고민 × 갈래마다
`rows`(저울) · `pats`(짜임) · `grp`(세운이 볼 자리). 사랑의 `@love` 는
짝을 보는 글자(남 재성 · 여 관성)입니다.

**문장 번호도 갈래를 따라 갈립니다** (`scale:…:@alone` · `pat:…:@broke` ·
`turn:…:yr=hit:@long`). 같은 번호로 묶으면 짝사랑에게 맞은 문장과 이별에게
맞은 문장의 공감률이 한 통에 섞입니다.

### 9-5. 두 번째 물음은 셈이 갈리는 자리에만

| 고민 | 두 번째 물음 | 두는가 | 까닭 |
|---|---|---|---|
| 일 | 「지금 일에서 무엇을 보오?」 자리·벌이·사람·버팀 | **둠** | 관성·재성·비겁·인성으로 **실제로 갈림** |
| 돈 | 「어디서 새오?」 | 이미 있음 | |
| 사랑 | 「누가 끝냈소?」 | **안 둠** | 여덟 글자가 모름 |

### 9-6. 세운 한 줄 — 몸에는 안 단다

```
올해는 丙午 세운, 겁재의 해가 되오. 물으신 혼자 마음만 쪽을 보는 재성
자리를 올해 건드리오 — 무슨 일이 생긴다는 말이 아니라, 그 자리가 올해
한 번 움직인다는 셈이오.
```

★ **몸 고민에는 안 답니다.** 건강을 해로 못 박으면 그건 예언이오.
★ 처음에 「…의 **해요**」로 썼다가 `test_표는_하오체_한_벌이다` 에
  걸렸습니다. 해(年)+요 라 하오체가 맞지만 해요체 「해요」와 글자가
  같아 말투 층이 못 가립니다. 대운 컷이 쓰는 「…의 해가 **되오**」로.

### 9-7. 잰 것

**답 하나가 바꾸는 컷** (표본 40명 · 유료 전부)

```
전   1컷 (topic_ask)
후   평균 3.25컷

money   pay 3.8  biz 3.5  estate 3.4  invest 3.0  many 3.4  none 3.2
work    org 3.5  biz 3.4  exam 4.0  move 3.5  rest 3.6
love    alone 3.9  dating 3.5  broke 3.6  long 2.7
people  home 3.3  work 3.1  old 3.3  new 3.5
dir     stay 3.5  move 3.3
health  sleep 2.2  belly 2.6  power 2.4  mind 2.2   ← 세운 줄을 안 달아 적음
```

**쏠림** — 공식 자(`tools/dup_rate.py`)

```
concern_pattern 0.90% · concern_scale 0.20% · concern_turn 0.27%
concern 1.17% · concern_face 0.13%                → 전부 문턱 2% 아래
```

★ **공식 자는 답 안 한 길만 잽니다.** 답한 길은 따로 쟀습니다 —
  답 안 한 때보다 나빠진 자리는 **일·내 일 벌이는 중 저울 0.29%→0.71%**
  하나였고 문턱 한참 아래입니다. 때는 오히려 낮아졌습니다(0.57→0.29,
  세운 줄이 갈래를 더해서).

★ 고민 하나씩 따로 재면 짜임이 2%를 넘는데(돈 6.86% 등), **답 안 한
  때부터 같은 숫자**이고 답해도 안 변합니다. 걸린 짜임이 0~1개인 사람이
  같은 글을 받는 몫입니다. 공식 자는 고민을 섞어 재서 0.90%입니다 —
  **자가 달라** 생긴 차이라 위반이라 부를 근거가 없습니다.

### 9-8. 겪은 것 — 정교하게 하려다 뭉개질 뻔했다

처음 설계는 「답이 가리키면 **조용한 칸이라도** 세운다」 였습니다. 같은
자로 재니 답 안 한 때는 문턱 아래던 돈 저울이 **답하면 4.29%** 로
뛰었습니다.

조용한 칸은 조용한 까닭이 있습니다 — 그 사람에게서 셀 것이 적어
누구에게나 같은 말(「없음」「적음」)이 나옵니다. 그걸 앞에 세우니 **답을
한 사람일수록 남과 같은 글**을 받았습니다. 소리 나는 칸끼리 차례만 바꾸게
고쳤더니 0.71% 아래로 내려왔습니다. `test_조용한_칸을_끌어올리지_않는다`
가 지킵니다.

### 9-9. 고치다 찾은 버그 — 대운 칸이 드는 해

`topic.turn` 에 `"year": f.saju_year + age` 가 있었습니다. §4-2 에서
리포트의 올해를 고친 것과 **같은 병**이 두 군데 더 있었습니다 —

```
engine/topic.py   turn 의 다음 대운이 드는 해
engine/report.py  대운 컷의 시작 해 · 끝 해 · 남은 해
```

`age` 와 대운 `start_age` 는 양력 해로 세는데 `saju_year` 는 입춘으로
셉니다. 1·2월생은 한 해 어긋났습니다.

```
1995-01-10 생   찍힌 해 2062 · 바른 해 2063
1988-01-31 생   찍힌 해 2035 · 바른 해 2036
```

`features.birth_year`(양력 생년)를 칸으로 올렸습니다. 그 도우미
`_birth_year` 는 **이미 있었는데 한 번도 안 쓰였습니다.** 남은 해는
나이끼리 뺍니다(`start_age - age`) — 해끼리 빼면 또 두 자를 섞습니다.
`test_대운_해는_양력_생년에_나이를_더한다` 가 지킵니다.

### 9-10. 남은 것

| 자리 | 형편 |
|---|---|
| 짜임이 안 바뀌는 갈래 | 그 명식에 걸린 짜임이 셋 이하면 차례를 바꿔도 같은 셋이 섭니다. 조건이 안 맞는 걸 억지로 내지 않는 게 맞습니다 |
| 사람·방향·몸의 두 번째 물음 | 여덟 글자가 더 가를 수 있는지 먼저 재야 합니다. 못 가르면 안 둡니다 |
| 공식 자가 답한 길을 안 잼 | `dup_rate` 가 `topic` 답을 넣어 재도록 하는 것이 다음 자리입니다 |

## 10. 갈래마다 **사실 셋** — 세고 나서 짚는다

### 10-1. 무엇이 어긋나 있었나 (2026-09-23)

되물음의 판정이 **갈래마다 사실 하나, 문장 하나** 였습니다.

```
방향 · 옮긴다   → 역마가 있나?      사실 하나 → 문장 하나
돈 · 굴린다     → 편재가 있나?      사실 하나 → 문장 하나
```

여덟 글자는 고민마다 수백 갈래를 가를 줄 아는데(§9-2 — 사랑만 해도
실효 177갈래) 판정은 한 자릿수만 썼습니다. 그래서 갈래를 바꿔도
답이 비슷하게 읽혔습니다.

재 보니 **갈래끼리 글이 54~74% 같았습니다.**

### 10-2. 무엇을 새로 세는가 — 아무것도 새로 안 셉니다

자들은 전부 `engine/topic` 과 `features` 가 **이미 세고 있던 값**입니다 —
투출 · 뿌리 · 공망 · 충 · 일지 합 · 신살 · 대운 · 세운 · 귀인 자리 ·
재고 · 오행 수 · 십신 수. 새로 점치는 것이 아니라 **세어 둔 것을
갈래에 대 보는 것**뿐이오.

```
판단   seed/topic.json  FACTS      갈래 29 × 사실 3 = 87칸
셈     engine/topic     _FACTS     자 46개 · fact_rows()
화면   engine/topic     ask_cut    <p class="cnt"><b>센 값</b> — 살림의 말</p>
검산   tests/test_topic_facts.py   모양·말·셈·팩폭
```

### 10-3. 사실 하나는 **센 값 + 살림의 말** 둘

```
편재 1자        — 한 번에 크게 드나드는 글자가 있소. 견적서 한 장에
                  그달 살림이 걸린 적이 있을 것이오.
다음 대운 36살 · 3해 남음
                — 판이 바뀌기 전에 끝낼 것과 넘길 것을 갈라 두시오.
```

★ **센 값에 「있소·없소」 를 넣지 마시오.** 바로 뒤 문장이 그 말을 또
  하게 되어 손님은 같은 말을 두 번 읽습니다. 앞은 **수**, 뒤는 **뜻**이오.

### 10-4. 못 세는 자리는 **모른다고 적는다**

시주를 모르는 사람에게 「시주에 받쳐 주는 글자가 없소」 라고 하던
자리가 있었습니다(`_ask_hit` 의 people/new). 그건 **없는 기둥을 채운
것**이오 — 이제 `None` 을 내고 `dunno` 로 말합니다. `daeun_left` 도
앞으로 올 대운이 없으면 안 셉니다.

### 10-5. 잰 것

```
                     전        후
갈래끼리 겹침   54~74%    22~42%
팩폭 평균          85        98   (최저 73 · 문턱 70)
```

무작위 400명 × 29갈래(11,600컷)로 훑어 —

```
가드에 걸린 컷 0 · 사실이 셋이 아닌 갈래 0
87칸 전부가 실제로 서고, **한쪽으로만 서는 칸이 0개**
```

★ 마지막 줄이 이 표의 값입니다. 400명에서 늘 참인 자는 **바넘 문장**이라
  아무것도 금하지 않소. 87칸이 다 갈린다는 것은 셈이 갈린다는 뜻이오.
