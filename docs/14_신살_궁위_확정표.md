# 14 · 신살(神殺) · 궁위(宮位) 확정표

> 05번 문서(계산엔진 사양서)에는 신살 장이 없었습니다. 이 문서가 그 자리를 채웁니다.
> **신살 표는 유파마다 다릅니다.** 지장간(05 §3)과 같은 원칙으로 하나를 확정하고
> 여기 남깁니다. **중간에 바꾸면 기존 사용자 결과가 달라집니다.**

구현 : `services/api/engine/sinsal.py` · 문장 : `seed/sinsal.json`

---

## 0. 왜 넣었나

오행·십신·신강약·용신·대운만으로는 사용자가 기대하는 것의 절반만 답합니다.
"누가 내 귀인인가", "조상 덕이 있는가" 는 신살과 궁위에서 나옵니다.
다만 이 영역은 단정하기 쉬운 자리라 **표현 규칙을 함께 못박습니다.**

## 5. 공망 (일주 순중공망)

```
공망1 = JI[(10 + 일지index - 일간index) % 12]
공망2 = JI[(11 + 일지index - 일간index) % 12]
```

검증 : 甲子 → 戌亥 · 甲戌 → 申酉 · 甲寅 → 子丑 · 丙申 → 辰巳

## 6. 궁위 (宮位)

| 기둥 | 누구 자리 | 함께 보는 것 | 나이 구간 |
|---|---|---|---|
| 년주 | **조상** | 뿌리 · 집안 · 물려받은 것 | 0~15세 |
| 월주 | 부모 · 형제 | 자란 환경 · 직장 | 16~30세 |
| 일주 | 자신 (일지 = 배우자) | 가장 가까운 사람 | 31~45세 |
| 시주 | 자식 · 아랫사람 | 말년 · 결실 | 46세~ |

### "누가 귀인인가" 산출

```
길신이 앉은 기둥 → 궁위로 읽는다
  년주에 천을귀인  → 윗대·손윗사람 쪽
  월주            → 부모·형제, 몸담은 조직
  일주            → 배우자 자리
  시주            → 아랫사람·후배

그 기둥 지지 본기의 십신 → 어떤 관계의 사람인가
  인성 손윗사람·스승   관성 조직·상사   재성 거래처·실무
  식상 후배·아랫사람   비겁 또래·동료
```

### "조상이 어떻게 돕는가" 산출

년주에 앉은 오행이 **이 사주의 용신인가** 로만 판단합니다.

```
용신과 같다        → "돕는 쪽"
이미 넘치는 오행    → "짐이 되는 쪽"
그 외              → "크게 관여하지 않는 쪽"
```

물려받은 결은 년간의 십신 묶음으로 읽습니다(인성=배움, 관성=명예, 재성=재물 …).

## 7. ★ 표현 규칙 — 이 영역이 가장 위험합니다

docs/11 과 CLAUDE.md 절대 규칙 2를 신살에 적용한 것입니다.

**쓰지 않는 말**

```
· "귀인이 반드시 나타난다"        시점·발생 단정
· "조상 덕에 잘 된다"            인과 확정
· "백호대살이라 사고가 난다"      질병·사고 예고 (가드에도 걸립니다)
· "도화라 바람난다"              사람에 대한 낙인
· "이 신살이 있으면 부자가 된다"   재물 보장
```

**쓰는 말**

```
· "전통적으로 ~라고 보던 자리요"
· "그 방향에서 온다고 읽소"
· "무엇을 준다고 정해 말하지는 않겠소"
· "옛 책은 ~로 읽었으나, 요즘은 ~로 봅니다"
```

`seed/sinsal.json` 의 `caution` 필드가 이 역할을 합니다.
백호대살·공망처럼 오해가 큰 신살에는 반드시 붙입니다.

## 8. 가드 주의 ★ 실제로 났던 사고

금지어 필터의 질병명 패턴이 `암` 한 글자를 잡던 시기가 있었습니다.

```
암록(暗祿)   → 통째로 삭제됨
청암거사      → 캐릭터 이름이 삭제됨
```

`seed/guard.json` 의 질병 패턴은 **한국어 단어 안의 글자를 잡지 않도록**
고쳐 두었습니다. 패턴을 손보면 반드시 아래를 도세요.

```bash
pytest tests/test_sinsal_share.py -k guard
```
