# 08 · 화면정의서 · IA

---

## 1. 정보 구조

```
성신당
├─ A 들어가다   a1 골목 → a2 이름 → a3 날 → a4 때 → a4b 성향 → a5 고민 → a6 명식 → a7 훅
├─ B 둘러보다   b1 진열대 · b2 스무 사람 · b3 그 사람 · b4 내 명식
├─ C 읽다       c1 표지 · c2 웹툰 · c3 대운맵 · c4 페이월 · c5 공유카드 · c6 피드백
├─ D 값을 치르다 d0 무료 6단 · d1 어디까지 · d1b 엿보기 · d2 결제 · d3 완료
├─ H 이어지다   h1 릴레이
├─ G 다시 오다  g1 오늘의 운세 · g2 회고 · g3 차 한 잔
├─ F 모으다     f2 인장첩
└─ R 남기다     r1 후기
```

---

## 2. 주 동선

**신규 유입**
```
a1 → a2 → a3 → a4 → a4b → a5 → a6 → a7(훅) 
   → d0(무료 6단) → d1 → d2 → d3 → c1~c5 → h1(릴레이)
```

**재방문**
```
푸시 → g1(일진) → b1(진열대) → b2/b3 → d1 → …
```

**릴레이 순환**
```
h1 → b3 → d1 → d2 → c1~c5 → h1 …   (세션 2회 제한)
```

## 3. 이탈 지점과 방어

| 지점 | 이탈 원인 | 방어 |
|---|---|---|
| a1 | 첫 3초 지루함 | 계절 장면 + 고양이 + 문 열림 연출 |
| a4 때 | 시각을 모름 | **"모르오" 를 크게.** 3주로 계산 |
| a4b 성향 | 검사 안 해봄 | "모르오 · 사주만으로" 버튼 |
| a5 고민 | 고르기 어려움 | 6개로 제한, 부제로 설명 |
| a6 명식 | 로딩으로 느껴짐 | 기둥 뒤집기 = 결과 발표 연출 |
| a7 훅 | 결제 압박 | **값을 아직 묻지 않음.** 무료 6단 우선 노출 |
| c4 페이월 | 잠금 반감 | 단어 4개만 가림. 답을 거의 다 읽은 상태 |
| h1 릴레이 | 강매 느낌 | 근거 명시 + "나중에" + 브레이크 표시 |

## 4. 전역 컴포넌트

**상단바** (a1 제외 전 화면)
```
[← 뒤로]  [화면명]  [日 일진]  [印 n]  [진열대]
```
- 히스토리 40 상한
- a2~a5 에는 [건너뛰기] 추가

**하단 고지** (h1, d2, r1)
```
본 서비스는 전통 명리학 해석에 기반한 자기이해·오락 목적 콘텐츠입니다.
의학적·법률적·재무적 판단의 근거가 아니며, 특정 결과를 보장하지 않습니다.
응답률 수치는 실제 사용자 응답 집계값이며 예측 적중률이 아닙니다.
```

## 6. 화면 상태 매트릭스

각 화면이 처리해야 하는 상태 조합

| 상태 | 값 | 영향 화면 |
|---|---|---|
| `hour_known` | true/false | a6, b4, c2, 훅 2단 |
| `axis4` | 4글자/null | a7 (2.5단 유무) |
| `paid` | false/one/all/sub | c4, d1, h1 |
| `read[]` | 0~20 | b2, f2, h1 |
| `cur` | 렌즈 id | c1~c4, 훅 대사, h1 |
| `concern` | 6종 | a7, d0, d1 |
| 계절 | 4종 | a1 |

**테스트 시 반드시 조합**: `hour_known=false` + `axis4=null` + `paid=false`
— 가장 잘 깨지는 조합입니다.
