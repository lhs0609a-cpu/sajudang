## `sajudang.html` 이 무엇인가

**동작하는 참조 구현체**입니다. 문서가 애매할 때 이 파일이 정답입니다.

포함된 것

- 실제 사주 계산 (절기·진태양시·서머타임·표준시 변천)
- 27개 화면 전체 흐름
- 훅 5단 · 무료 6단 · 릴레이 엔진
- 20인 캐릭터 렌즈
- 성향 4글자 대조
- 장면 아트 24개 (SVG 자리표시)
- 애니메이션 명세 (클릭 시 프롬프트 표시)

**한계**

- 만세력 절기가 근사 테이블 (±1일 오차) → 05번 문서 참조해 교체 필수
- 문장 뱅크가 클라이언트에 노출 → 서버로 이관 필요
- DB 없음 (statement_log, 회고 루프 미작동)
- 결제 미연동

---

## 3줄 요약

1. **계산은 서버에서, 정밀하게.** 만세력이 틀리면 전부 무너집니다.
2. **문장은 뱅크 조합으로 시작.** LLM은 hit율 데이터가 쌓인 뒤에.
3. **가드레일을 먼저 붙이고 기능을 붙입니다.** 11번 문서를 개발 전에 읽으세요.
