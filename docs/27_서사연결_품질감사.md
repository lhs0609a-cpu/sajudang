# 첫 방문부터 결과까지: 서사 연결 품질 감사

2026-09-09. 이전 기능 검사를 전체 경험의 품질 검토로 보고한 것은 잘못이었다. 기존 1만 건 엔진 검사에서는 소개 없는 인물 등장과 잘못된 화자를 잡지 못했다. 이번에는 화면의 연결과 문장의 전제를 별도로 검사한다.

## 일관성 기준

- 풍운도령은 처음부터 등장하는 길잡이이며 첫 해석도 담당한다. 이후 해석자는 사용자가 고른 인물이다.
- 입력·결제·오류 안내는 쉬운 설명체, 해석 대사는 캐릭터의 말투를 사용한다.
- 길잡이의 고정 대사를 사용자의 심리를 맞힌 결과로 포장하지 않는다. 성찰 질문은 명식의 근거와 함께 제시하며, 맞지 않는 경험을 받아들이도록 강요하지 않는다.
- 사용자 행동·감정을 알 수 없는 경우 과거형으로 확정하지 않는다.
- 구매 범위, 재방문 경로, 공유되는 정보는 세계관 용어만으로 설명하지 않는다.

## 검사 범위

- `tools/verify_story_continuity.cjs`: 320·390·768px 진입 화면, 기존 다른 캐릭터에서 새 시작, 실제 빈 입력부터 시각 미상 첫 해석까지, 20명의 실제 결과 화면. 결제 제공자는 차단한다.
- `tools/vulnerability_sim.py`: 20명 × 6고민의 120조합을 균형 있게 포함한 합성 명식 1만 건. 현재 소스 파일 해시를 결과에 기록한다. 예외·본문 생성·추가 입력·동일 본문·종합 결과 누락을 검사한다.
- 전체 Python 검사에서 새로 발생한 브레이크 문구·줄바꿈 회귀는 수정하고 해당 검사 6개를 재통과했다. 기존 초상화 정렬 3개는 이 작업으로 해결했다고 표시하지 않는다.

엔진 1만 건은 브라우저 1만 회가 아니며, 실제 사용자의 이해도·이탈률·구매 만족도도 아니다. 인물과 화면의 연결 결함은 이번 소스·브라우저 검사에서 확인했다. 실제 ‘안 맞음·돈 아까움’의 빈도는 수집된 사용자 응답과 구매·환불 데이터를 별도로 확인해야 한다. 모든 취약점을 없앴다는 보증은 하지 않는다.
