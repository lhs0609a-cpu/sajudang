# 전환 개편 구현 기록 · 2026-09-08

설계 기준은 [21_전환율_전면개편_설계.md](21_전환율_전면개편_설계.md)다. 이 문서는 실제 앱에 반영한 범위와 검증 한계를 기록한다. 운영 배포 또는 전환율 상승을 의미하지 않는다.

## 실제 반영

- **첫 방문:** 고민 중심의 첫 카피와 무료 시작 버튼. 고민 → 생년월일·출생지·성별 → 시간의 3단계로 단축했다. 별칭과 성향은 선택 입력이다. 고민·성별·상품은 사용자가 직접 고른다.
- **계산:** 기존 역법·명식 계산을 유지한다. 시간 미상은 시주를 비우고 해석한다. 명식 뜻, 계산 근거, 보정 내역 및 다른 계산 방식의 명식을 펼쳐 볼 수 있다. 실제 계산 완료 후 진행한다.
- **무료 가치:** 기존 엔진 해석에 고민별 실천 문장 하나와 복사 버튼을 더했다. 이 실천 문장은 일반적 행동 제안이며 사주 계산 결과가 아니라는 출처를 표시한다. 무료 전용 인물에서는 추가 상품을 권하지 않는다.
- **구매:** 개별 상품을 먼저 보여 주고 전체·정기 상품은 펼쳐 비교하게 했다. 상품 선택, 실제 추가로 열리는 내용, 서버 주문 금액, 환불·자동결제 조건과 결제 버튼을 한 화면에 배치했다. 결제 전에는 완료 URL만으로 성공을 표시하지 않는다.
- **표현:** Noto Sans KR와 Noto Serif KR 두 계열, 본문 16px·주요 버튼 56px·터치 영역 44px 기준으로 조정했다. 입력·구매 화면의 인위적 대기와 큰 장면 영역을 줄였다. 고양이는 시작·선택·복사·완료에 반응하며 동작 줄이기 설정을 따른다.
- **관리자:** 관리자 도구는 기본으로 숨긴다. 기존 종합점수는 ‘자동 문장 검사 · v1’로 명시하고 실제 만족도·정확도·전환율과 구분한다. 접힌 기본 HTML 설명도 분량 검사에 반영한다.
- **전환 계측:** 신규 흐름 노출, 계산 완료, 행동 복사와 서버 결제 승인을 추가했다. 최근 30일 첫 노출 코호트의 7일 전환을 순서대로 집계한다. 브라우저 이벤트로 결제 승인을 위조하거나 완료 주소 방문을 결제로 세지 않는다. 단위는 익명 브라우저이며 사람 수와 같지 않다.
- **결제 처리:** 승인·웹훅의 계정 단위 잠금, 주문 소유권 확인, 복구 가능한 지급 처리, 구매 횟수 중복 가산 방지, 안정적인 승인 멱등 키를 추가했다. 응답이 불명확하면 PG 조회로 주문·금액·승인 상태를 대조한다. 공개 주문 조회에서 내부 키와 세션 정보를 제거했다.

입력·구매 화면 통합으로 더 이상 사용하지 않는 장면 8종은 `ARCHIVED_SCENES`로 명시했다. 기존 정적 이미지와 영상 원본은 보존했다.

## 검증 자료

상세 로그·스크린샷·실행 스크립트는 `output/conversion-implementation/`에 있다.

- 실제 로컬 API에 연결한 모바일 브라우저 검증 통과: 선택 확인, 이름 생략, 시간 미상, 훅 중립 응답 5회, 서버 실천 문장, 상품 자동 선택 없음, 같은 화면 주문 준비, 미결제 완료 접근 방지, 320px 입력 화면, 실행 오류 없음.
- 이 브라우저 검증에서는 PG 요청과 외부 폰트 요청을 막았다. 실거래 및 웹폰트 로딩 환경 검증은 포함하지 않는다.
- 결제·구독·계측·신규 응답 계약 관련 89개 검사 통과. 역법 94개를 포함한 앞선 선택 회귀 검사 187개 통과. 겹치는 실행이므로 합산하지 않는다.
- 역법 교차 검사 300건, 분포 검사 3,000건, 문장 중복 검사 3,000건, 주어 누락 검사 통과.
- Next.js 프로덕션 빌드 및 타입 검사 통과. 로컬 확인용 빌드의 API 주소는 `127.0.0.1:8016`이므로 이 산출물을 운영에 그대로 배포하지 않는다.
- 전체 회귀 검사: **1,230개 통과, 2개 건너뜀, 3개 실패** (`full-tests-final.log`, 336초). 실패는 모두 기존 초상화 알파 여백·머리 정렬 검사다. 이번 변경에 초상화 파일 변경은 없다. 이번 개편 관련 실패는 수정 후 재검증했다.

## 남은 운영 검증과 후속 범위

1. 운영 설정에서 실제 결제·복원·환불·정기결제 전 과정을 확인하고 별도로 배포한다.
2. A/B 실험 배정, 매출·환불 후 순매출 지표, 실사용 전환율과 모바일 성능을 수집한다. 1만 명 이용 부하 검사는 아직 수행하지 않았다.
3. 20개 인물의 모든 조건부 해석 문장을 전면 재작성한 상태는 아니다. 기존 문장 은행을 유지하며 신규 무료 실천과 구매 전 설명을 반영했다. 다음 콘텐츠 개선은 인물·명식 간 반복률과 실제 읽기 피드백으로 검증한다.
4. 기존 초상화의 상단 여백·머리 높이 문제를 별도 이미지 작업으로 수정한다.

결제율 상승과 심리 효과의 크기는 아직 측정하지 않았다. 설계 문서의 1만 명 시나리오는 관측치가 아닌 가정이다.
