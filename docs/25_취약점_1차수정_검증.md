## 구현한 변경

- **계산 경합(C01):** 대안 비교에 요청별 계산 기준을 전달한다. 기존 기본 계산 정책과 상수는 유지하며, 전역 값을 임시 변경하지 않는다. 동시 실행 중 기존 시주가 유지되는 회귀 시험을 추가했다.
- **복원·환불(C02/C11):** 복원 시 이전·새 세션의 결제 잠금을 잡고 소유권을 다시 확인한다. 구독에 연결된 주문의 소유자도 이동한다. 반복 기기 복원 후 환불하면 현재 구독이 종료되고 카드 키가 제거된다. 이동 전 구독을 들고 있던 갱신 작업은 청구하지 않는다. 사용자/관리자 환불도 잠금 전후 소유권 변경을 검사한다.
- **실제 재시도(C03/C13):** 리포트, 훅, 무료 해석, 상품 목록, 분석지, 일진에서 재조회하도록 했다. 리포트 재시도는 추가 입력을 유지한다. 결제 승인 요청을 자동 반복하는 버튼은 추가하지 않았다.
- **조회 상태(C04/C05):** 구매 내역의 로딩·조회 실패·빈 결과를 구분한다. 구독 조회 실패에도 오류와 재조회 버튼을 표시한다.
- **캐시·재방문(C06/C07):** 명식 캐시에 KST 기준 날짜와 엔진 버전을 검사한다. 오래되거나 사라진 명식은 재계산 응답을 보내고, 웹이 기존 로컬 입력으로 한 번 재계산한 뒤 원래 조회를 재시도한다. 같은 명식 ID인지 검증하며 구매 권한은 건드리지 않는다. 새 원입력 서버 보관은 추가하지 않았다. 브라우저의 입력까지 지워졌으면 재입력이 필요하다고 안내한다.
- **입력·설명(C08/C09/C10/C14):** 미래 생년월일·14세 미만·지원하지 않는 도시를 API에서도 거절한다. 핵심 훅·리포트 표지·분석지에서 시각 미상은 3기둥·6글자로 안내한다. 계산 서버 장애를 입력 실수처럼 안내하지 않는다.
- **재발행(C12):** 검증된 계산 오류 환불은 무료 재발행 주문과 열람 권한을 실제로 만든다. 같은 환불을 다시 요청해도 PG 취소와 재발행이 중복되지 않는다. 구매 내역에서 재발행을 표시하고, 금액 0원 재발행에 일반 환불 버튼을 표시하지 않는다. 구독 재발행은 기존 만료일을 유지하며 카드를 재등록하거나 자동결제를 재개하지 않는다.
- **방문·권한 보존(C15/C16):** 일진 방문 수는 KST 날짜마다 초기화한다. 일진 서버 날짜도 KST로 통일했다. 복원/구독 처리 시 주문 인덱스에 1년/2년 TTL을 붙이지 않는다. 기존에 만료된 연결은 주문번호로 다시 복원해야 한다.
- **구매 기대:** 선택한 상품에 추가 정보가 필요한 해석이 있으면 구매 전에 알린다. 전체 상품에는 이미 읽은 내용도 포함되며, 모든 인물의 본문이 한 명 상품보다 길어지는 것은 아니라는 설명을 추가했다.
- **문장:** 첫 훅의 일반 10종·연애 4종에 대해 생활 단정과 그 원인을 확정하던 문장 28개를 확인 질문과 한계 설명으로 바꿨다. 훅 캐시를 새 문구 버전으로 분리했다. 인장첩의 근거 없는 사용자 성과 비교와 리포트 표지의 과거 경험 단정도 제거했다. 화면 문구 스냅샷을 갱신했다.
