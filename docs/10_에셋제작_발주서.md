## 4. 색 변형 대응 ★

일간 10색 × 계절 4 를 전부 찍으면 클립이 폭증합니다.
해당 장면은 **무채색으로 뽑고 앱에서 색을 입힙니다.**

```css
.scene-video{ filter: grayscale(1) brightness(1.15) }
.scene-tint { position:absolute; inset:0; background:var(--c);
              mix-blend-mode:color; opacity:.62; pointer-events:none }
```

**대상** : `gate` `altar` `roadmap` `cardbg` `seat`

```
seat  캐릭터 20색 → 1클립
gate  계절 4 × 일간 10 → 계절 4클립
```

## 5. 공유 카드 특칙 ★

`cardbg` 는 **정지 PNG 를 반드시 함께** 만듭니다.


**중앙은 반드시 비워두세요** — 캐릭터와 이름은 앱에서 오버레이합니다.

## 6. 화면에서 프롬프트 꺼내기 ★

장면 그림을 **클릭하면** 그 장면의 제작 프롬프트가 뜹니다.
신살 인물(docs/16)도 같습니다.

```
① 시작 이미지 · 제미나이     복사 버튼
② 모션 · 힉스필드            복사 버튼   ← 영상 앵커가 이미 붙어 있음
③ 착색 · CSS                 무채색 대상 장면만
```

프롬프트 원문은 `reference/sajudang.html` 에서 **추출해서** 씁니다.
손으로 옮기면 어긋나므로 다시 뽑을 때는:

```bash
node tools/extract_asset_prompts.js <참조구현체에서_뽑은_js> apps/web/public/asset-prompts.json
```

담긴 것: 장면 24 · 신살 인물 13 · ANIMBASE · TINT · 파이프라인 안내.

## ★ 프롬프트 전량을 한 장으로 뽑기

화면에서 장면·인물을 눌러도 한 항목씩만 보입니다. 40장을 순서대로
훑으려면 텍스트 한 장으로 뽑으세요.

```bash
node tools/prompt_sheet.js reference/sajudang.html 에셋_프롬프트_전체.txt
```

`에셋_프롬프트_전체.txt` — 40항목. 항목마다 ① 제미나이 이미지 프롬프트,
② 힉스필드 모션 프롬프트, 폴더 경로, 규격, 주의가 붙습니다.

| | |
|---|---|
| 장면 24종 | `reference/sajudang.html` 의 `SCN` · `MO` 를 실제로 평가해 뽑습니다 |
| 대문 4계절 | `SEA` 를 네 번 갈아 끼웁니다. 한 번만 돌리면 여름 하나만 나옵니다 |
| 신살 인물 13종 | `seed/figure_prompts.json` — **여기가 원본입니다** |

`apps/web/public/asset-prompts.json` 은 산출물입니다. 고칠 일이 있으면
원본을 고치고 다시 뽑으세요.

```bash
node tools/extract_asset_prompts.js reference/sajudang.html apps/web/public/asset-prompts.json
```

### 대문만 계절을 탑니다

꽃이 계절마다 다릅니다 — 벚꽃 · 능소화 · 국화 · 매화. 착색으로는
꽃 모양을 못 바꾸므로 **그림 자체가 넉 장**이어야 합니다.
들어가는 자리도 계절 폴더입니다.

```
public/scene/gate/spring/   summer/   autumn/   winter/
```

`tests/test_asset_prompts.py` 가 이 넷이 서로 다른지, 각 계절에 제
꽃만 들었는지, 앱이 계절 폴더를 보는지 검사합니다.
