# 첫 해석의 밀도와 다음 질문 · 2026-09-09

## 적용한 흐름

입구에서는 ‘잘 버티는 힘이 다른 자리에서는 나를 지치게 할 수 있다’는 질문을 제시한다. 다섯 마디의 무료 해석을 읽으며 답하면, 다음 실제 마디의 제목을 보여준다. 건너뛰기 버튼은 다시 넣지 않았다.

무료 요약에서 일반적인 확인 질문보다 실제 `why` 본문의 핵심 강조 문장과 설명을 먼저 표시한다. HTML을 평문으로 바꾸어 렌더링하며, 새 성격 주장을 임의로 생성하지 않는다. 바로 아래에는 출처, 전통 해석이라는 성격, 캐릭터 고유의 관점과 질문, 오늘의 행동을 둔다. 원문에 강조 문장이 없으면 기존 확인 질문으로 돌아간다.

다음 해석에는 서버가 실제로 반환한 잠긴 본문의 첫 문장 두 개를 표시한다. 먼저 다루는 것은 현재 흐름과 필요한 힘이다. 가격·내용을 확인하는 버튼으로 이어지고, 실제 결제 범위와 샘플은 기존 서버 미리보기를 사용한다. 비공감 답변이 있는 경우 이를 인정하는 기존 화면을 유지하며, 받아들이지 않은 패턴에서 추가 구매를 유도하는 예고는 표시하지 않는다.

## 품질 오류 수정

- `lens_cuts._counted`가 숨은 기운까지 가중한 점수를 반올림해 ‘글자 수’라고 표현하던 것을 실제 겉글자 개수로 수정했다. 강약·용신 계산과 희소도 표 자체는 변경하지 않았다.
- 출생 시간이 없으면 훅과 본문·근거·예고의 ‘여덟 글자’를 실제 사용한 여섯 글자로 맞춘다.
- 관성·재성·식상이 2개 이상일 때 무조건 ‘둘’이라고 쓰던 문장을 실제 개수로 고쳤다.
- 희소도는 숨은 기운까지 포함한 기준임을 본문에 명시한다. 겉글자에 없는 기운과 숨은 기운까지 전혀 없는 경우를 구분한다.
- 회상 질문의 ‘선택 이유을’처럼 조사가 어긋나는 문장을 수정했다.

## 캐릭터의 구현 기준

공통 계산 사실 위에 캐릭터별 분석 축과 관점을 얹는다. 풍운도령은 버티는 힘과 도움받는 힘, 행수는 들어오는 것과 남는 것, 연담은 연락과 경계를 다룬다. 기존 20명 × 6개 고민의 120개 질문이 서로 다르고 입력·근거가 유효한지 검사한다. 이번 변경이 20명의 초상 원본이나 모든 본문을 새로 제작했다는 뜻은 아니다. 풍운도령의 예전 얼굴·애니메이션과 하묘는 유지한다.

## 검증 범위

프로덕션 빌드 통과. 기존 기능 검사 1,277개 및 새 계산·서술 회귀 검사 3개 통과(분할 실행). 기존 초상 원본 정렬 검사 파일은 별도 미해결 항목으로 유지한다. 신규 회귀 검사의 두 초기 실패는 시간 유무에 따른 약한 기운 선택과 본문 강조 태그를 고려하지 않은 검증식이 원인이었고, 실제 출력 기준으로 수정 후 통과했다.

모바일 24개 화면과 결제 안내까지 이어지는 6개 동선 검사를 통과했다. 공유 화면의 일시적인 연결 시간 초과는 별도 재확인해 통과했다. 모의 검증이며 실제 고객 결제·전환율을 측정한 결과는 아니다.
