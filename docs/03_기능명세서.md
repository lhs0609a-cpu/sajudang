## 전역 규칙

- 상단바: 뒤로(히스토리 40 상한) · 일진 · 진열대 · 인장 카운트
- a1 에서는 상단바 숨김. a2~a5 에는 건너뛰기 버튼
- 모든 화면에 출구가 최소 1개 (고아·막다른 화면 0)
- `prefers-reduced-motion` 이면 애니메이션 전부 정지
