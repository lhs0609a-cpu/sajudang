# 첫 인사 영상·음성 제작안

2026-09-09 사용자 요청: 새로 만든 이미지의 주요 캐릭터가 실제로 움직이고, 초반에만 목소리가 나오며 배경음이 함께 흐르는 경험.

## 연출

첫 길잡이는 풍운도령이다. 현재 공개 초상 `/char/pungun/bust.webp`를 기준 이미지로 사용한다. 기존 옆모습 영상은 새 얼굴을 대체하는 데 사용하지 않는다. 카메라를 고정하고 한 번의 자연스러운 눈 깜빡임, 약한 호흡, 작은 고개 인사와 머리카락 끝 움직임을 넣는다. 얼굴·의복·화풍·조명은 유지한다. 반복적인 좌우 흔들림이나 이미지 전체 확대를 실제 캐릭터 동작으로 대신하지 않는다.

대사: “풍운도령이오. 먼저 그대의 고민을 듣고, 무료 해석부터 안내하겠소.”

차분한 한국어 남성 목소리로 8~12초 이내에 읽는다. 인사 전에 긴 정적을 두지 않는다. 입 움직임을 넣는 경우 최종 음원에 맞춘 립싱크 검수가 필요하다. 확인되지 않은 목소리 모방은 하지 않는다.

## 재생 흐름

- 입장 화면에서 선택해 재생한다. 기다리지 않고 무료 해석으로 진행할 수 있다.
- 성공적으로 시작한 음성은 같은 탭의 방문 동안 자동으로 반복하지 않는다.
- 인사 중에는 배경음을 낮추고, 종료·건너뛰기·화면 이탈 시 원래 음량을 복원한다.
- 소리 끄기를 누르거나 탭을 숨기면 인사를 멈춘다. 동작 줄이기 설정에서는 영상 대신 같은 초상과 자막을 보여 준다.
- 훅 단계의 자동 음성 재생은 제거한다. 안내 목소리를 첫 인사에 한정한다.

## 파일과 검수

영상 목표: 세로 3:4, H.264 MP4, 24fps, 720px 이내, 3MB 이내, 영상 자체는 무음. 음원 목표: 한국어 MP3, 192kbps 이하. 별도 음원을 인사 플레이어에서 한 번만 재생한다. BGM은 기존 `outside.mp3`를 사용한다.

제작 후 얼굴 일치, 손·입 왜곡, 하오체 발음, 첫 프레임 연결, 대사 종료 시점, 모바일 재생 및 음소거를 실제 파일로 확인한다. 검수한 파일 경로만 `apps/web/lib/entry-media.ts`에 설정한다.

현재 상태: 새 동작 영상과 음성은 미제작이다. 연결된 영상 생성 도구와 운영 서버의 ElevenLabs 설정이 없다. 경로를 비워 두어 미완성 인사 재생 버튼이나 기존 얼굴 영상이 노출되지 않는다. 배경음 켜기는 실제 기존 음원으로 제공한다.

소리 재생은 사용자의 명시적인 클릭에서 시작한다. [MDN 자동 재생 안내](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)의 사용자 동작 및 실패 처리 기준을 따른다.
