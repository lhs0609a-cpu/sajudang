# 전체 모션 제작 — 2026-09-09

요청 범위는 새 이미지로 실제 동작 영상을 생성하고 서비스에 적용하는 것이다. 기존 영상을 새로 만든 것처럼 재사용하거나 이미지 확대 효과를 영상 생성으로 보고하지 않는다.

현재: 원본 검증 완료, 영상 53개와 한국어 첫 인사 음성 1개의 생성 목록 및 큐 도구 준비. 실제 생성 0개. FAL_KEY 미설정으로 생성 요청은 제출되지 않았다.

## 실행

`FAL_KEY`를 로컬 실행 환경에 설정한 뒤 아래 명령을 사용한다. 키는 저장소나 브라우저에 넣지 않는다.

```powershell
python tools/generate_motion.py plan
python tools/generate_motion.py submit
python tools/generate_motion.py collect
```

submit은 실제 생성 요청을 보낸다. collect를 다시 실행하면 진행 중인 작업부터 이어서 결과를 받는다. 결과는 Git에서 제외된 `out/motion`에 저장된다. 요청이 수락되었는지 확인할 수 없는 통신 오류는 `submission_unconfirmed`로 남기며 자동으로 재결제 요청하지 않는다. 이 경우 공급자 요청 기록을 확인하고 상태를 복구한다.

영상: [Kling 이미지→영상 API](https://fal.ai/models/fal-ai/kling-video/v2.5-turbo/pro/image-to-video/api). 한국어 대사: [ElevenLabs Multilingual v2 API](https://fal.ai/models/fal-ai/elevenlabs/tts/multilingual-v2/api). 둘 다 fal 계정 하나로 요청하도록 구성했다. 남성 내레이션의 초기 후보는 George이며, 한국어 발음과 캐릭터 적합성은 생성 후 청취해서 판단한다.

원본 파일 해시를 검사하므로 얼굴 이미지가 바뀐 상태에서 이전 제작 목록을 그대로 실행하지 않는다. 각 영상은 얼굴·손·눈의 왜곡, 화풍, 반복 연결, 첫 프레임과 끝 프레임을 확인한 뒤 H.264 MP4와 VP9 WebM으로 인코딩해 표의 폴더에 배치한다. 공개 장면은 clip.mp4 / clip.webm / poster.jpg, 큰 초상은 clip.mp4 / clip.webm을 사용한다. 신살 인물은 기존 정지 이미지가 있어도 새 영상이 있으면 영상을 우선하도록 수정했다. 동작 줄이기 설정에서는 정지 초상을 유지한다.

첫 인사 영상과 음성은 별도 경로에 넣고 `apps/web/lib/entry-media.ts`에 두 경로를 함께 설정한다. 무음 영상에 내레이션을 더하는 방식이며 입 모양이 대사를 말하는 립싱크로 검증된 것은 아니다. 실제 한국어 발화와 입 모양을 맞추려면 최종 음원으로 립싱크 제작·검수가 추가로 필요하다.

폐기된 화면의 8개 배경은 제작 대상에서 제외했다. 공유용 정지 이미지·작은 목록 초상·가격 및 입력 문장은 계속 읽기 쉽게 유지한다.
