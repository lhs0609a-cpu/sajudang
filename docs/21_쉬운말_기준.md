# 21 · 쉬운 말 기준

> 손님이 한 말 (2026-09-11)
> "모든 캐릭터든 모든 말을 다 쉽게 설명해 줘. 어려운 단어 쓰지 말고,
> 어려운 단어 쓸 때는 반드시 쉬운 말로 설명하고. 초등학생도 이해가 될 정도로.
> 뭔 말인지 모르면 무슨 소용이야."

목표는 하나입니다 — **초등학생이 읽고 무슨 말인지 안다.**
뜻을 바꾸지 않고, 말만 쉽게 합니다.

---

## 1. 뜬 낱말을 쓰지 않는다

아는 낱말인데 무슨 뜻인지 모르는 말이 제일 문제입니다. 어려운 한자어보다 더 흔합니다.

| 뜬 말 | 이렇게 |
|---|---|
| 자리 · 쪽 · 데 | **무엇인지** 적는다 — 회사, 집, 돈, 친구, 사람들 앞, 가족 |
| 결 · 기운 · 판 · 틀 | 성격, 버릇, 일, 규칙, 계획 … 가리키는 것을 그대로 |
| 온도 · 그릇 · 마디 · 칸 · 철 | 비유라면 바로 뒤에 풀이 (2번) |
| 흐름 · 힘 (혼자 올 때) | 무엇을 하는 힘인지 — 시작하는 힘, 끝내는 힘, 버티는 힘 |

전 → 후

- 가르는 사람이라 흐릿한 자리에서 유독 답답하오.
  → 그대는 맞고 틀림을 딱 잘라 가르는 사람이라, 기준 없이 「대충 알아서 해」 하는 곳에서 유독 답답하오.
- 결이 다른 십 년이었다는 말이오.
  → 그 열 해에는 일이 주인공이 아니었다는 말이오.
- 곁자리가 고요하오. 온도가 잘 안 흔들리오.
  → 그대 발밑 글자(일지)가 조용하오. 기분이 잘 안 흔들린다는 말이오.

## 2. 비유를 쓰면 바로 뒤에 푼다

비유만 던지면 수수께끼입니다. **그 자리에서** 「— ~라는 말이오」 로 풉니다.

- 곳간과 문간같이, 쌓는 데와 드나드는 데가 다르오.
  → 창고와 대문처럼 따로 있소 — 돈을 모으는 힘과 돈이 들고 나는 힘은 서로 다른 힘이라는 말이오.

비유 소재는 **살림의 말**로 — 솥·밥·삯·장터·그릇·손·발·계절·눈금. 그림이 되는 낱말입니다.

## 3. 어려운 말 (명리 용어)

- `engine/terms.py` 의 `MEANING` 에 있는 말(비견·상관·용신·대운·신강 … 56가지)은
  **그대로 써도 됩니다.** 풀이 층이 리포트에서 **처음 나오는 자리**에 괄호 풀이를 붙이고,
  컷 밑에 그림 한 줄(`PICTURE`)을 답니다.
  - ★ **괄호 풀이를 손으로 달지 마세요.** 손으로 달면 「관성(나를 누르는 …(…))」 처럼 겹칩니다.
- 그 목록에 **없는** 어려운 말(투출·통근·궁위·격국·조후 …)은
  쉬운 말로 바꾸거나, 문장 안에서 「~, 곧 ~라는 뜻이오」 로 풀어 씁니다.
- 용어를 지우자는 것이 아닙니다. 용어는 이 집의 근거입니다. **그 자리에서 풀면** 근거가 됩니다.

## 4. 말투

- 뱅크는 **하오체 한 벌 · 호칭 「그대」 한 벌**입니다. `voice.speak` · `voice.address` 가
  캐릭터마다 갈아 끼웁니다. 쉬운 말로 바꾸면서 말투를 바꾸지 마세요.
- 문장 끝은 「~오 · ~소 · ~시오 · ~요」. 명사나 「~인지.」 로 끝내지 않습니다
  (말투 감사가 반말로 잡습니다).
- 「그대로」 를 쓰지 마세요 — 호칭 층이 「그대」 로 읽어 갈아 끼웁니다. 「바뀌지 않고」 「있는 대로」.
- 캐릭터가 **제 목소리로 이미 적은 곁말**(`flavor.SIDE`)은 그 캐릭터 말투를 지킵니다.

## 5. 바꾸지 않는 것

- `{자리표시}` · `%s` — 엔진이 채웁니다
- 태그 수 (`<b>` `<br />` …) — 굵게 칠한 자리가 훑어읽기 자리입니다
- 한자 · 숫자 — 셈에서 온 것입니다
- **뜻** — 새 사실, 새 예언, 새 조언을 보태지 않습니다
- 가드 — 적중률 · 과학 · 통계 · 「반드시」 · 병명 · 수명 · 이혼 단정 · 투자 시점. 병·사고를 단정하는 비유도 안 됩니다

## 6. 길이

- 원문보다 크게 늘리지 않습니다 (1.5배 안쪽). 쉬운 말은 짧을수록 쉽습니다.
- 한 문장 60자 안팎. 길면 둘로 끊습니다.
- 한 마디(말풍선) 120자 · 4문장 안쪽 (`.\dev.ps1 say`).

## 6.5 쉬운 것으로는 모자랍니다 — **장면**을 댄다 (2026-09-17)

> 손님이 한 말
> "글에 비유가 적어서 공감이 잘 안가, 너무 다 추상적이야.
>  구체적으로 내 이야기구나 딱 보자마자 소름돋게 만들어야는데."
> "모든 페이지 비유랑 진짜 쉽게 이해될 수 있도록 설명했어?
>  구체적으로 날카롭게? 사례중심으로?"

쉬운 말은 **못 알아듣는 것**을 막습니다. 그렇다고 「내 얘기」가 되지는
않습니다. 셋을 같이 봐야 합니다 (`tools/like_me.py`) —

| | 무엇인가 | 보기 |
|---|---|---|
| 그림 | 표지(처럼·같소) + **눈에 보이는 물건** | 「눌러 둔 용수철이 손을 떼면 튀는 것과 같소」 |
| 장면 | 손님이 **어제 겪은 자리** | 「회의에서 옳은 말을 하고 퇴근길에 후회한 적이 있을 것이오」 |
| 내 수 | 나이 · 해 · 개수 | 「상관 2개 · 불 0자 · 36살」 |

셋 중 하나도 없이 끝나는 컷은 **누구에게나 맞는 글**입니다.

### 장면은 어디서 오는가

지어낸 사건이 아니라 **되물을 수 있는 자리**입니다. 「스물여덟에
회사를 그만뒀소」 는 소설이고, 「거절하려다 카톡에 네라고 답한 적이
있을 것이오」 는 손님이 제 기억에서 대 볼 수 있습니다. 틀릴 수
있어야 맞았을 때 소름이 돋습니다.

표는 `engine/real.py` 에 있고, **컷마다 딛는 축이 다릅니다** —
없는 것(weak_el) · 용신 · 쥔 것(strong_el) · 저울(십신) · 때(대운
국면) · 얼굴(신강약) · 위로(희소도) · 물음(flow). 한 표를 여덟 컷에
돌려 쓰면 한 장에 같은 말이 여덟 번 납니다.

### 지킬 것

- **칸마다 눈에 보이는 물건**을 댑니다. 「요즘 가장 피하고 싶은 그
  일」 은 맞는 말이나 그림이 안 그려집니다 — 카드값 · 단톡 · 견적 ·
  이력서 · 구독처럼 어제 손에 쥔 것을 대세요.
- **머리말에 뜬 낱말을 쓰지 않습니다.** 「세어 보면 이런 **자리**요」
  처럼 적으면 표 전체가 흐릿해집니다 (1번 표).
- **명식 컷에는 안 붙입니다.** 여덟 글자는 무엇을 물었든 같습니다
  (`tests/test_concern_spread`).
- **「이번 주 한 가지」 에도 안 붙입니다.** 시키는 일이 둘이 되면
  손님은 하나도 안 합니다. 거기는 **처방 자체**를 고민 축으로 고릅니다.
- 옛 물건(곳간·가마솥·장터)으로만 그리면 「옛날 얘기」로 읽힙니다.
  말투는 옛말이되 **물건은 오늘 것**으로 (`likeme` 의 옛 칸이 잽니다).

## 6.9 「어렵다」는 낱말이 아니라 **끼어듦**이었다 (2026-09-25)

손님이 무료 구간 전문을 붙여 놓고 말했다 — 「왜 전체가 풀이가 어렵고
와닿지가 않지? 전체 다 그래.」

그런데 이 집의 자는 **전부 초록불**이었다. `easy_audit` 흐림 6% ·
`hard_words` 0 · `dup_rate` 통과 · `worth` 74. 까닭은 **재는 단위**였다.

| 자 | 재던 단위 |
|---|---|
| `dup_rate` | 같은 문장이 **여러 사람 사이에서** 겹치는가 |
| `easy_audit` | **한 문장**이 흐린가 |
| `likeme` | 천 자에 장면이 몇 줄인가 |

손님이 읽는 단위는 **한 장**이다. 한 장 안에서 같은 괄호가 다섯 번,
같은 이치가 네 번, 시키는 일이 넷 나오는 것은 위의 어느 자에도 안
걸린다 — 문장 하나하나는 쉽고, 사람끼리도 안 겹치니까.

한 장을 실측하니 **그 사람 얘기가 60%**뿐이었다.

```
그 사람 얘기   8,655자   60.0%
잠긴 것 목록   2,257자   15.7%   ← 파는 말
근거 줄        1,755자   12.2%   ← 꼬리가 매번 같음
사전 상자      1,216자    8.4%   ← 상자 4개 · 항목 14.6개 (한 상자에 17항목)
괄호 풀이        534자    3.7%   ← 한 장에 54.9개 · 한 낱말 최다 5.3번
```

고친 뒤 (같은 자 · 120명):

| | 전 | 후 |
|---|---|---|
| 한 장 | 10,274자 | **8,796자** |
| 문장 되풀이 | 0.8종 · 45자 | **0** |
| 근거 꼬리 최다 | 4.0번 · 322자 | **3.0번 · 72자** |
| 괄호 되풀이 | 30.1개 · 1,095자 | **6.7개 · 559자** |
| 사전 상자 | 4.0개 · 14.6항목 | **1.0개 · 3항목** |
| 시키는 일 | 3.6개 | **1.0개** (한 컷에 둘 이상: 0) |
| 맛보기 상자 자리 | 2곳 + 끝 페이월 | **1곳** |
| 뜬 수 | 30.7개 | **6.3개** |

### 여기서 배운 것 — 다음에 또 날 사고

1. **괄호는 한 장에 두 번까지.** 거리 규칙(`GLOSS_AGAIN`)만 보면
   14,000자 장에서 열다섯 번 비워져 한 낱말이 다섯 번 풀린다. 훅도
   단마다 `seen` 을 새로 만들어 다섯 번까지 풀고 있었다.
2. **근거와 본문은 한 묶음이다.** 따로 세면 같은 컷의 근거와 본문에
   같은 괄호가 나란히 선다. 화면은 근거를 컷 **위**에 그린다.
3. **이치 자리에서 뜻풀이를 하지 마라.** `why.RULE` 네 줄이 풀이표와
   같은 말로 시작해 「월지(태어난 달의 아래 글자…)는 태어난 달의
   아래 글자…」 가 나갔다. 풀이는 괄호가 맡고, 이치는 **왜 그렇게
   읽는지**만 댄다.
4. **점수는 근거가 아니다.** `strength_score` 가 여섯 자리에서
   「중화(3)」 으로 샜다. 대신 그 판정에 실제로 들어간 것을 댄다 —
   태어난 달과 발밑이 받쳐 주는가. 손님이 만세력을 펴고 확인할 수 있다.
5. **단위 없는 수는 벽이다.** 「정관 0」 「식상 3」 — 「0자」 라야
   손님이 무엇을 센 수인지 안다. 마지막에 한 번 훑어 단다
   (`report._name_counts`).
6. **광고는 한 장에 한 곳.** 무료 컷마다 붙이니 페이월로 부르는 말이
   25.6번이었고, 같은 물음이 한 장에 네 번 섰다. 읽다가 자꾸 광고판에
   부딪히면 손님은 글을 못 믿는다.
7. **`josa` 는 낱말째 돌려준다.** `{name}{josa(name,…)}` 로 쓰면
   「삼거리 노파삼거리 노파가」 가 된다 — 스무 명 가운데 열아홉의 첫
   컷 첫 줄이었다. 문장 되풀이 셈으로는 안 걸린다(한 문장 **안**이라).

## 7. 재는 법

```powershell
python tools/easy_audit.py --show      # 흐릿한 문장 · 어디서 왔나
python tools/hard_words.py             # 풀이 없이 나오는 어려운 말
python tools/dull_audit.py --show 1    # ★ 한 장 **안**의 끼어듦 (6.9)
python tools/plain_split.py check DIR  # 고쳐 쓴 조각 검사 (자리표시·태그·한자·숫자·가드)
.\dev.ps1 easy                         # 스무 사람 · 모든 화면 전부
.\dev.ps1 likeme                       # 그림 · 장면 · 내 수 (천 자당) · 맨 컷
.\dev.ps1 sharp                        # 쉬움 × 날카로움 — 둘 다 낮은 자리부터
```

★ `easy` 와 `dull` 은 **다른 것을 잰다.** 앞은 문장 하나가 흐린가,
  뒤는 한 장 안에서 같은 말이 끼어드는가. 손님이 「어렵다」 할 때는
  둘 다 봐야 한다 — 2026-09-25에 앞만 보고 초록불이라 여겼다.
