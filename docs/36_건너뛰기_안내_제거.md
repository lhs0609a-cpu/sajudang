# 건너뛰기 안내 제거 · 2026-09-09

사용자 요청에 따라 응답 건너뛰기 버튼과 집계 설명, 상단 건너뛰기 링크, 본문 위에 뜨던 ‘한 번에 다 보겠소’, 로딩 화면의 건너뛰기 버튼을 제거했다. 해석 요청 결과가 준비되면 추가 연출 대기 없이 본문이 열린다.

무료 해석은 다섯 마디에 ‘그렇소 / 아니오 / 잘 모르겠소’로 답한 뒤 요약으로 이어진다. 불확실한 답은 기존과 같이 동의로 집계하지 않는다. 출생 시간을 모르는 경우의 입력 선택지는 유지한다. 재생 중 소리를 멈추는 제어는 ‘인사 멈추기’로 표시한다.

관련 자동화도 바뀐 실제 동선을 따르도록 갱신했다. 예전 응답 건너뛰기 경로 대신 중립 응답 다섯 번을 진행하며, 보고서는 건너뛰기 버튼 클릭 없이 본문이 나타나는지 확인한다. 이전 전환 개선 문서의 건너뛰기 UI 설명은 이 요청으로 대체한다.
