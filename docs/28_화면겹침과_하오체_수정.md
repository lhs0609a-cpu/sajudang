# 화면 겹침과 하오체 수정 — 2026-09-09

사용자 캡처에서 도령 소개 아래의 시작 버튼을 FAQ가 덮었다. 데스크톱의 고정 hero와 별도 FAQ 배치에 소개 카드 높이가 반영되지 않은 문제였다. 첫 화면을 모든 폭에서 문서 흐름으로 배치해 내용 높이만큼 늘어나도록 수정했다.

이전 문서의 서비스 설명체·캐릭터별 말투 구분은 이번 사용자 요청으로 대체한다. 공개 화면, 오류·결제 안내, 고양이 대사, 스무 해석자의 결과를 하오체로 통일한다. 캐릭터별 관점과 호칭, 계산 근거는 유지한다. 오래된 훅 문장이 캐시에서 나오지 않도록 캐시 이름도 변경했다.

고양이 공통 SVG를 둥근 크림색 얼굴, 큰 눈, 분홍 볼, 작은 발과 방울로 수정했다. 첫 화면에도 등장하며 기존 동작 및 동작 줄이기 설정을 유지한다.

## 검증

- `tools/verify_entry_layout.cjs`: 320~1920px의 9개 화면 크기에서 hero/FAQ 비겹침, 가로 넘침 없음, 버튼 실제 클릭 가능, 다음 입력 화면 진입, 실행 오류 없음 확인. 1536×728, 960×455는 확대 시 줄어드는 유효 화면 크기를 포함한다.
- `tests/test_voice_clean.py`: 20명 × 6개 고민 × 출생시간 유무의 240개 생성 결과에서 말투 혼용 검사. 어미 검사만으로 문학적 완성도를 보장하지는 않는다.
- 기존 해요체 문장을 요구하던 테스트를 같은 의미의 하오체로 갱신했다. 계산이나 접근 조건을 완화하지 않았다.
- Next.js 프로덕션 빌드 성공. 전체 Python 검사에서 기존 초상화 상단 정렬 관련 3건은 별도 미해결 항목이다. 이 변경은 초상화 원본을 수정하지 않는다.

이 검증은 실제 사용자 1만 명의 경험이나 결제율을 측정한 결과가 아니다. 신규 영상 생성은 별도 작업이다.
