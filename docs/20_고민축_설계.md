# 20. 고민축 설계 — 돈을 물으면 돈을 세는 집

> 2026-09-06. 손님이 짚은 것:
> **"돈에 대해 물었는데 돈 관련 이야기는 전혀 구현이 안 되어 있어."**
>
> 09-05 에 고친 것은 「여섯 칸에서 **낱말**이 갈리는가」였습니다.
> 이 문서가 고치는 것은 「여섯 칸에서 **셈**이 갈리는가」입니다.

---

## 0. 무엇이 어긋났나 — 재 본 값

| 고민이 갈리는 자리 | 09-05 기준 |
|---|---|
| 훅 5단 | 낱말표 3개(`STAB` `MYTH_TG` `IGNITE`)·마감 이름(`NAME_AT`) |
| 유료 리포트 22컷 | 고민으로 갈리는 컷 **1개**(`concern`) + 짜임 최대 2개 |
| 짜임 20개 중 「돈」에 걸리는 것 | **4개** (군겁쟁재·재다신약·식상생재·재성없음) |
| 「돈」에서 **세지 않는 것** | 정재/편재 갈래 · 투출 · 궁위 · 재고 · 공망 · 충 · 재성↔용신 · **대운의 재성 시기** |
| 「몸」에서 **세지 않는 것** | 오행↔장부 배속 · 고립 · 관살/식상/인성의 압 · 대운이 미는 쪽 |
| 넉 자(성향 4글자) | 성격 대조만. **고민과 안 만남** |
| 고민별 추가 물음 | **없음** (`context` 8종은 캐릭터 몫이지 고민 몫이 아님) |

한 줄로: **고민은 낱말만 갈리고 셈이 안 갈렸습니다.**
돈을 골라도 재성을 「개수 하나」로만 보고, 그마저 22컷 중 한 컷에서만 씁니다.

이건 이 집의 포지션과 정면으로 어긋납니다. 「맞히는 집」이 아니라
**「근거 대는 집」**인데, 물은 자리에서 근거를 안 대고 있었습니다.

---

## 1. 바깥에서 찾은 것

### 1-1. 실무는 고민마다 **다른 자리**를 본다

돈을 볼 때 실무가 세는 것은 「재성 몇 개」가 아닙니다. 공개된
명리 해설·유료 서비스 가이드가 공통으로 드는 판정 축은 이렇습니다.

| 축 | 무엇을 보는가 |
|---|---|
| 재성의 갈래 | 정재(고정 수입·저축) vs 편재(사업·투자·큰 돈) |
| 일간 강약 ↔ 재성 무게 | 신왕재왕(들 힘 있음) / 재다신약(감당 못 함) / 재약신강(쥘 게 얕음) |
| 식상생재 | 만든 것이 값이 되는 다리가 나 있는가 |
| 비겁 대 재성 | 군겁쟁재 — 나눌 입이 몇인가 |
| 재고(財庫) | 재성 오행의 고지(辰戌丑未)가 지지에 있는가 |
| 투출/암장 | 천간에 드러났는가, 지지 속에만 있는가 |
| 궁위 | 년(물려받은·이른) 월(일·자란 데) 일(곁 사람) 시(늦자리) |
| 공망·충 | 재성이 앉은 자리가 비었는가, 부딪히는가 |
| 대운·세운 | 재성운·식상운·비겁운이 **언제** 드는가 |
| 용신 관계 | 재성이 살리는 쪽인가 누르는 쪽인가 |

몸을 볼 때는 축이 통째로 바뀝니다 — 오행의 태과·불급과 장부 배속,
고립, 조후(한습·조열), 충·형, 십신의 압(관살 과다·식상 과다·인성 과다),
그리고 대운이 **이미 넘치는 쪽**을 더 미는가.

핵심은 하나입니다. **고민이 바뀌면 보는 축이 바뀌지, 같은 축에
다른 낱말을 붙이는 게 아닙니다.**

### 1-2. 넉 자(MBTI)와의 결합 — 바깥의 관행과 우리 자리

학술 쪽에는 MBTI 외향/내향과 사주 오행 분포의 연관을 본 연구가
있고(외향 ↔ 목·화 비율, 내향 ↔ 금·수 비율), 상업 서비스는 대개
「MBTI 유형 + 일간/십신」을 이어 붙여 성격 프로필을 두껍게 만듭니다.

우리는 **성격 프로필을 두껍게 하려고 넉 자를 받지 않습니다.**
이 집에서 넉 자의 쓸모는 하나뿐입니다 —

> 넉 자는 **그대가 스스로 고른 답**이고, 여덟 글자는 **고를 수 없었던 것**이다.
> 그 둘이 어긋난 자리가 곧 「그대가 그렇게 보이려고 애쓰는 자리」다.

그러니 결합의 자리도 하나입니다: **어긋남을 고민의 말로 옮긴다.**
「J인데 여덟 글자는 P요」가 아니라
**「모으는 결로 살려 하는데, 글자는 흐르는 결이오 — 그래서 돈이
모이는 게 아니라 지나가오」** 라야 합니다.

덤으로 이 결합은 **재검사 흔들림**(5주 뒤 39~76%가 다른 유형)을
서사로 흡수합니다: 「여덟 자는 안 바뀌오. 넉 자는 지난달과 다를 수 있소.」

### 1-3. 넘지 않는 선 (docs/11 · CLAUDE.md)

| 도메인 | 금지 |
|---|---|
| 몸 | 질병명 단정 · 처방 · 수술/출산 시기 · 수명 |
| 돈 | 특정 종목 · 투자 시점 지시 |
| 전체 | 적중률 · 과학적 입증 · 「반드시 ~한다」 |

그래서 몸 축은 **병을 말하지 않고 결을 말합니다.** 옛 표가 오행을
어느 장부에 붙여 읽었는지는 **사실**이므로 전할 수 있습니다 —
「그대는 간이 나쁘오」는 금지, 「옛 표는 목을 간·담과 눈에 붙여
읽었소. 그대는 목이 바닥이오」는 허용. 판정이 아니라 **인용 + 셈**입니다.

돈 축은 **시점 지시**를 안 합니다. 「올해 사시오」는 금지,
「재성 대운은 마흔둘, 2043년부터 열 해요」는 허용 — 이건 예언이
아니라 **달력**입니다. 그 해에 무슨 일이 생긴다고 말하지 않습니다.

## 2. 설계 원칙

1. **고민은 축을 바꾼다.** 낱말이 아니라 세는 값을 바꿉니다.
2. **셀 수 있는 값만.** 판정 조건은 전부 Feature Store 에서 나옵니다.
   조건이 안 맞으면 **안 냅니다** — 억지로 붙이면 바넘입니다.
3. **근거는 보이되 규칙은 감춘다.** 「재성 1 · 천간에 안 드러남」은 내고,
   문턱값·연산자는 안 냅니다.
4. **때는 달력으로.** 나이·연도를 박되 그 해의 사건은 말하지 않습니다.
5. **물음은 짜임이 걸렸을 때만.** 「돈을 골랐으니 수입원을 내시오」는
   묻는 게 아니라 받아 내는 것입니다.
6. **저장하지 않는다.** 고민 물음의 답은 계산하고 버립니다.

## 3. 구조 — 고민 하나가 **다섯 자리**를 연다

```
고민 하나 →  ① 저울   그 자리에서 무엇을 세는가        (셈 4~5줄)
             ② 짜임   그 셈들 사이의 관계               (pattern.py)
             ③ 때     그 자리가 대운에서 언제 바뀌는가  (나이·연도)
             ④ 얼굴   넉 자가 이 자리에서 어떻게 나오나 (axis4 × 고민)
             ⑤ 물음   더 물어야 할 것 하나              (선택지만)
```

구현 자리:

| 자리 | 파일 | 컷 id |
|---|---|---|
| 판정 | `engine/topic.py` (새로) | — |
| 문장표 | `seed/topic.json` (새로) | — |
| 짜임 | `engine/pattern.py` (확장) | — |
| ① 저울 | `engine/report.py` | `concern_scale` |
| ② 짜임 | `engine/report.py` | `concern_pattern` |
| ③ 때 | `engine/report.py` | `concern_turn` |
| ④ 얼굴 | `engine/report.py` | `concern_face` |
| ⑤ 물음 | `engine/extras.py` (`topic` 종) | `topic` |
| 무료 한 줄 | `engine/bank.py` 훅 3단 마감 | — |

컷 넷은 전부 **공통 컷(min_level 1)** 입니다. 값 등급 차이는 관점 컷이
집니다 — 고민은 「어느 자리를 보고 읽느냐」지 「얼마를 냈느냐」가
아닙니다 (기존 `concern` 컷과 같은 판단).

## 4. 돈 — 확정표

### 4-1. 저울 (`concern_scale`)

세는 순서가 곧 읽는 순서입니다.

| 칸 | 조건 (셀 수 있는 값) | 갈래 |
|---|---|---|
| 쥐는 자리 | `정재`·`편재` 개수 | 없음 / 정재만 / 편재만 / 둘 다 |
| 드러남 | 재성이 천간에 있는가 | 드러남 / 숨음 |
| 앉은 자리 | 재성이 앉은 궁위 | 년 / 월 / 일 / 시 (없으면 건너뜀) |
| 드는 힘 | 신강약 × 재성 개수 | 신왕재왕 / 재다신약 / 재약신강 / 고름 |
| 다리 | 식상 개수 ≥1 & 재성 ≥1 | 놓임 / 끊김 |
| 새는 데 | 비겁 개수 | 0~1 / 2 / 3 이상 |
| 창고 | 재성 오행의 고지가 지지에 | 있음 / 없음 |
| 빈 자리 | 재성 지지가 공망 / 충 | 걸림 / 없음 |
| 살리는가 | 재성 오행 == 용신 | 용신 / 기신 / 무관 |

**재고(財庫) 확정표** — 재성 오행의 묘고 지지입니다.

| 재성 오행 | 고지 | 예 |
|---|---|---|
| 목 | 未 | 庚·辛 일간 |
| 화 | 戌 | 壬·癸 일간 |
| 토 | 辰 | 甲·乙 일간 |
| 금 | 丑 | 丙·丁 일간 |
| 수 | 辰 | 戊·己 일간 |

> 土庫를 辰으로 잡습니다. 戌로 보는 유파도 있으나 한 벌만 씁니다.
> 이건 계산이 아니라 **선택**이라 `constants` 와 같은 급으로 못박습니다.

### 4-2. 짜임 (`concern_pattern`) — 돈 축에 새로 붙는 것

기존 4개(군겁쟁재·재다신약·식상생재·재성없음)에 더합니다.

| 이름 | 조건 | 무엇을 가리키는가 |
|---|---|---|
| 신왕재왕 | 신강 & 재성 ≥2 | 들 힘과 쥘 것이 같이 있음 |
| 재성 암장 | 재성 ≥1 & 천간 투출 없음 | 손에 안 잡히는 꼴로 옴 |
| 재고 | 재성 고지가 지지에 | 쌓아 두는 자리가 있음 |
| 재성 공망 | 재성 지지가 공망 | 공들인 만큼 안 남던 자리 |
| 탐재괴인 | 재성 ≥2 & 인성 ≥1 & 신약 | 벌리려다 받치는 걸 깎음 |
| 재생관 | 재성 ≥1 & 관성 ≥1 | 돈이 자리로 바뀌는 길 |
| 시상편재 | 시주 천간이 편재 | 늦자리에서 크게 벌리는 결 |

### 4-3. 때 (`concern_turn`)

대운 목록에서 **재성·식상·비겁** 대운이 드는 칸을 셉니다.

```
지금 칸    대운 십신 → 「지금은 무슨 판인가」 (bite.PHASE 와 같은 결)
다음 칸    바뀌는 나이 · 연도 = 태어난 해 + start_age
재성 칸    재성 대운이 드는 나이 · 연도 (없으면 「이 여덟 칸에는 없소」)
```

문장 꼴:

> 지금은 **인성 대운**이오. 마흔둘까지요.
> 재성 대운은 **마흔둘, 2043년부터 열 해**요.
> 그 열 해가 무슨 일을 준다는 말이 아니오 — **읽는 자리가 바뀐다**는 말이오.

없으면 없다고 합니다: 「여덟 칸 안에 재성 대운은 없소. 그런 사람이 넷 중 하나요.」

### 4-4. 얼굴 (`concern_face`) — 넉 자 × 돈

돈에 걸리는 축은 **둘**입니다. 넷을 다 말하면 성격검사가 됩니다.

| 축 | 돈에서 무엇인가 |
|---|---|
| T/F | 값을 무엇으로 매기는가 — 숫자로(T) / 사람으로(F) |
| J/P | 모으는 결인가(J) / 흐르는 결인가(P) |

```
넉 자를 적었으면   입력 글자 ↔ 사주 4축(같은 축) 을 대조
안 적었으면        사주 4축만으로 같은 문장 (「글자에서 뽑아 보았소」)
```

겹치면 「겹친 자리」, 어긋나면 **고민의 말로 옮긴 어긋남**을 냅니다.

> **J → P** 모으는 결로 살려 하는데 글자는 흐르는 결이오.
> 그래서 예산은 늘 서고, 예산대로 간 달은 드무오.

### 4-5. 물음 (`topic`)

돈에서 더 묻는 것은 **둘**, 선택지만 받습니다 (자유 입력 금지).

```
지금 돈은 어디서 오오?   월급 / 장사·사업 / 여러 갈래 / 아직 없소
어디서 새오?             사람에게 / 벌리다가 / 안 새는데 안 모이오 / 모르겠소
```

대조하는 자리:

| 적은 것 | 글자에서 대는 근거 |
|---|---|
| 월급 | 정재 유무 |
| 장사·사업 | 편재 유무 · 식상생재 |
| 여러 갈래 | 편재 · 역마 |
| 아직 없소 | 재성 0 · 인성 과다 |
| 사람에게 샌다 | 비겁 개수 |
| 벌리다가 샌다 | 편재 · 신약 |
| 안 모인다 | 재성 공망 · 재고 없음 |

「모르겠소」는 **노출로만** 셉니다 (`answer=null`). 그렇소·아니오 둘만
두면 애매한 사람이 거짓 답을 눌러 공감률을 오염시킵니다.

## 5. 몸 — 확정표

### 5-1. 저울

| 칸 | 조건 | 갈래 |
|---|---|---|
| 넘치는 쪽 | `strong_el` 개수 | 3 이상 / 2 이하 |
| 바닥 | `weak_el` 개수 | 1 미만 / 그 외 |
| 고립 | 그 오행이 1인데 생해 주는 오행이 0 | 고립 / 아님 |
| 온도 | 화 − 수 | 몹시더움 / 더움 / 고름 / 추움 / 몹시추움 |
| 들 힘 | 신강 / 중화 / 신약 | 회복의 결 |
| 흔들림 | 일지 충 · 지지 충 쌍 개수 | 0 / 1 / 2 이상 |
| 압 | 관성 ≥3 / 식상 ≥3 / 인성 ≥3 / 편인&식신 | 눌림 / 소진 / 안으로 쌓임 / 도식 |
| 날 | 양인 · 백호 · 괴강 | 있음 / 없음 |
| 대운 | 지금 대운 오행이 넘치는 쪽인가 바닥인가 | 미는 판 / 채우는 판 / 무관 |

### 5-2. 오행 ↔ 장부 확정표

**인용으로 냅니다.** 「옛 표는 ~로 읽었소」 — 진단이 아닙니다.

| 오행 | 옛 표가 붙인 자리 | 넘칠 때 결 | 모자랄 때 결 |
|---|---|---|---|
| 목 | 간·담 · 눈 · 힘줄 | 뻗대다 부딪힘 · 머리가 조임 | 결정을 미룸 · 눈이 먼저 시달림 |
| 화 | 심·소장 · 잠 · 혈 | 안 꺼짐 · 밤이 늦어짐 | 시작이 안 걸림 · 기운이 낮음 |
| 토 | 비·위 · 소화 · 살 | 붙들고 근심함 · 무거워짐 | 받쳐 줄 데가 없음 · 끼니가 흐트러짐 |
| 금 | 폐·대장 · 살갗 · 숨 | 날카로워짐 · 마름 | 못 끊음 · 숨이 얕아짐 |
| 수 | 신·방광 · 뼈 · 귀 | 고임 · 겁이 앞섬 | 못 고임 · 밑천이 빨리 바닥남 |

★ 「병이 온다」·「~에 걸린다」로 쓰지 않습니다. 표의 낱말은 **자리**지
증상이 아닙니다. 가드(`seed/guard.json`)가 질병명을 다시 봅니다.

### 5-3. 몸의 때 · 얼굴 · 물음

* **때** — 대운 오행이 넘치는 쪽이면 「무거워지는 칸」, 바닥을 채우면
  「트이는 칸」. 나이·연도만 박고 사건은 안 답니다.
* **얼굴** — 몸에 걸리는 축은 **S/N**(몸 신호를 알아채는가)와
  **J/P**(리듬을 정해 두는가).
* **물음** — 「요즘 먼저 무너지는 자리」 잠 / 소화 / 기력 / 마음.
  적은 것과 오행 배속이 겹치면 「글자와 겹치오」, 어긋나면 「글자는
  다른 데를 가리키오」로 갑니다. 둘 다 근거를 답니다.

## 6. 나머지 넷 — 확정표 (2026-09-06 보강)

돈·몸만 깊고 나머지가 얕으면 「다 똑같아」가 다시 돌아옵니다. 그래서
넷도 같은 꼴로 채웠습니다. 여기서 새로 **세기 시작한 것**은 넷입니다 —
격(格) · 형(刑) · 무리(삼합·방합) · 천간합, 그리고 배우자궁의 십신.

### 6-1. 새로 세는 값 — 전부 지지·천간을 표와 맞춰 보면 끝

**형(刑)** — 옛 책이 다툼·시비로 읽던 자리. 파(破)·해(害)는 **안 씁니다**
(유파가 갈립니다). 사고·재판을 예고하는 표로 쓰지 않습니다 (docs/14 §7).

| 꼴 | 조건 |
|---|---|
| 삼형 | 寅巳申 또는 丑戌未 **셋 다** |
| 상형 | 子卯 둘 다 |
| 자형 | 辰·午·酉·亥 중 같은 글자가 **둘 이상** |
| 반형 | 삼형 중 **둘만** (가볍게 읽음) |

**무리(局)** — 지지가 한 기운으로 뭉쳤는가. 굳은 차례대로 봅니다.

| 꼴 | 조건 | 오행 |
|---|---|---|
| 삼합 | 申子辰 / 寅午戌 / 巳酉丑 / 亥卯未 **셋 다** | 수 / 화 / 금 / 목 |
| 방합 | 寅卯辰 / 巳午未 / 申酉戌 / 亥子丑 **셋 다** | 목 / 화 / 금 / 수 |
| 반합 | 삼합 중 **왕지(子·午·酉·卯) 포함 둘** | 그 삼합의 오행 |

**천간합** — 甲己 · 乙庚 · 丙辛 · 丁壬 · 戊癸. 일간이 다른 기둥의 천간과
묶이는가만 봅니다. 「합화(合化)」까지는 안 봅니다 — 그건 유파 판단입니다.

**격(格)** — 월지에서 무엇으로 서는가. 실무의 차례를 그대로 따릅니다.

```
① 월지가 일간의 록(비견)이면 건록격, 겁재 자리면 양인격
② 월지 지장간 중 천간에 투출한 것의 십신이 격
   ★ 비견·겁재는 격 이름으로 안 씀 — ①에서 이미 부름
③ 투출이 없으면 월지 본기의 십신이 격
```

성패·구응까지는 **안 봅니다.** 유파가 갈리고, 이 집은 셀 수 있는 데까지만
냅니다. 표본 300명에서 열 격이 23~36명씩 고르게 나옵니다.

### 6-2. 고민별 저울 (칸은 다섯까지, 드문 칸이 앞)

| 고민 | 세는 칸 | 짜임 수 | 얼굴 축 | 물음 |
|---|---|---|---|---|
| 일 | 관성 갈래 · **격** · **형충** · 신강약 · 투출 · 궁위 · 식상 · 인성 · 비겁 | 15 | E/I · J/P | 지금 자리 — 조직 / 혼자 / 준비 / 쉬는 중 |
| 사랑 | 배우자성 수 · **배우자궁 십신(10)** · **혼잡** · **천간합** · 투출 · 궁위 · 일지 충합 · 도화·원진 · 공망 | 12 | T/F · E/I | 기존 `partner` `meet` |
| 사람 | 비겁 · **형** · **무리** · 관성(선) · 식상(말) · 인성(받음) · 일지 충합 · 원진 | 13 | E/I · T/F | 누구와 걸렸소 — 집안 / 일터 / 오랜 사이 / 새 사람 |
| 방향 | 역마 · **무리** · 화개 · **힘이 흐르는 쪽** · 용신 방위 · 판이 바뀔 때 · 관성 유무 | 9 | S/N · J/P | 두 갈래 — 남는다 / 옮긴다 |

새로 붙은 짜임: 살인상생 · 식신제살 · **일지 형** · 삼합국 · 방합국 ·
역마 재성. 짜임은 전부 **43개**가 되었고 고민마다 9~15개가 걸립니다.

**용신 방위 확정표**: 목=동 · 화=남 · 토=가운데 · 금=서 · 수=북.
이사·이직의 「좋은 방향」으로 단정하지 않고 **「기운이 도는 쪽」**으로만 씁니다.

### 6-3. 재 본 값 (표본 300명 · 칸이 실제로 서는 비율)

```
일     격 100%  · 형충 70% · 투출 82% · 궁위 26%
사랑   배우자궁 100% · 일지 79% · 도화·원진 69% · 천간합 27% · 혼잡 23%
사람   형 54% · 무리 48% · 받는 자리 70%
방향   힘이 흐르는 쪽 100% · 무리 48% · 화개 68%
```

쏠림은 `.\dev.ps1 dup` 으로 다시 쟀습니다 — 저울 최다 점유 0.20%,
짜임 0.93% (문턱 2%).

## 10. 적용 기록 (2026-09-06)

설계대로 붙이면서 **세 군데가 설계와 달라졌습니다.** 재보고 고친 것이라
여기 남깁니다.

### 10-1. 근거 줄은 전부 **수**로

처음에는 저울의 근거를 「재성이 앉은 자리 월주」처럼 글자로만 적었습니다.
`tests/test_topic.py` 가 잡았습니다 — 수가 없으면 손님이 세어 볼 수
없고, 세어 볼 수 없으면 그건 근거가 아니라 선언입니다.
지금은 **모든 칸의 근거에 수가 있습니다** (「재성 2 · 앉은 자리 월주」).

### 10-2. 컷마다 축을 **셋** 곱함

공통 컷의 최다 점유 문턱은 2%입니다. 축 둘로 만든 컷이 이랬습니다 —

| 컷 | 축 둘일 때 | 축 셋으로 | 무엇을 더했나 |
|---|---|---|---|
| 저울 | 0.23% | — | (칸이 다섯이라 이미 넉넉) |
| 때 | 1.92% | **0.27%** | 이 칸의 시작·끝 나이와 남은 해 |
| 얼굴 | 3.12% | **0.13%** | 그 축이 **무엇을 세어 나왔는지** |
| 짜임 | 2.50% | **1.00%** | 몇 중 몇이 걸렸는가 + 신강약 맺음 |

`.\dev.ps1 dup` 전량 **[OK]** — 훅 중복률 0.1%, 유료 컷 최다 점유
2% 초과 0개.

더한 것이 전부 **세는 값**이라는 점이 중요합니다. 가짓수를 늘리려고
문장을 늘린 것이 아니라, 근거를 대다 보니 가짓수가 따라왔습니다.

### 10-3. 수를 말로 낼 때 — 조사·서술격 네 자리

* 자리표시와 조사 **사이에 태그**가 끼면 받침을 못 봅니다 —
  「나무 이 여덟 글자에」. `topic._fmt` 가 태그를 넘어서 봅니다.
* 서술격도 받침을 봅니다 — 「하나요」 「둘이오」.
* `count_word` 는 0을 「없음」, 6 이상을 「여섯 넘게」로 줍니다. 그대로
  끼우면 「쥘 자리는 없음이오」 「나눌 입이 여섯 넘게요」가 됩니다.
  수를 서술어로 낼 때는 **말이 끝난 꼴**(`topic._pred`)로 냅니다 —
  「하나도 없소」 「여섯이 넘소」.
* 이음말도 받침을 봅니다 — 「넷고」가 아니라 「넷이고」.

### 10-3b. 옛 조사 자리 (기록)

* 자리표시와 조사 **사이에 태그**가 끼면 받침을 못 봅니다 —
  「나무 이 여덟 글자에」. `topic._fmt` 가 태그를 넘어서 봅니다.
* 서술격도 받침을 봅니다 — 「관성이 하나이오」가 아니라 「하나요」,
  「둘이오」. 수를 말로 내면 받침이 낱말마다 달라 손으로 못 박습니다.

### 10-4. 물음은 돈만 둘, 나머지는 하나

물음은 마찰입니다. 돈만 「어디서 오오 · 어디서 새오」 둘을 받고
(둘 다 골라야 보냅니다), 일·사람·방향·몸은 하나입니다. 사랑은
이미 `partner` `meet` 가 있어 새로 만들지 않았습니다.

### 10-5. 남은 것

* 화면: `components/TopicAsk.tsx` 를 붙였습니다. 답은 `extras.topic`
  으로 실려 가고 **저장되지 않습니다.**
* 검사: 이 기계에는 Python 3.11 venv 가 없어(sxtwl 은 3.12 휠이 없고
  MSVC 도 없음) `.\dev.ps1 engine-check` 를 **못 돌렸습니다.**
  그래서 관문을 CI 에 두었습니다 — `.github/workflows/engine-check.yml`
  이 밀 때마다 3.11 로 같은 다섯을 돌립니다.
  `tests/test_topic.py` 28건과 나머지 검사는 순수 파이썬 절입 대역으로
  돌려 통과를 봤고, 절입 자체를 보는 검사(`test_calendar`)는 그 대역의
  오차(1~4분)로 어긋납니다. **venv 를 만든 뒤 한 번 돌려야 합니다.**
