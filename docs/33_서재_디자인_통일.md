# 성신당 · 밤의 서재 디자인 적용

2026-09-09. 이전 디자인 문서의 색상·화면 구성보다 이 문서와 `apps/web/styles/atelier.css`를 우선한다.

## 화면의 규칙

- 먹빛 녹색 바탕 `#141614`, 종이색 본문 `#f3ecdc`, 절제된 황동색 강조 `#ddc493`. 인장은 붉은 갈색으로 구분한다.
- 제목과 인물 대사는 Noto Serif KR, 설명·가격·버튼은 Noto Sans KR. 제목·본문·보조 설명의 크기와 행간을 공통화했다.
- 데스크톱은 성신당 표지와 읽는 페이지의 두 칸, 모바일은 한 칸이다. 화면 전체를 덮던 흐린 배경은 제거하고 페이지 안의 장면은 유지한다.
- 주요 버튼은 최소 56px 높이. 입력·선택·구매 상품·오류 상태마다 같은 테두리와 색상 규칙을 쓴다.
- 첫 화면은 질문 → 무료 해석 버튼 → 풍운도령 소개 → 안내묘 → 서비스 설명 순서다. 고양이는 같은 캐릭터와 하오체를 유지한다.
- 입력, 해석자 목록, 해석 여섯 탭, 무료·유료 안내, 요약, 오늘, 내 서재, 릴레이, 공유, 약관, 404와 오류 화면에 공통 디자인을 적용했다. 관리자 로그인에도 같은 색상과 폼 규칙을 적용했다.
- 장면 서술의 평서체를 하오체로 수정했다. 제목·버튼의 짧은 명사형과 원문 인용은 문장 종결형으로 강제 변환하지 않는다.

## 풍운도령 보존

사용자의 “예전 캐릭터랑 애니메이션 그냥 쓰자” 요청을 반영했다.

- 정면 초상과 인사 포스터를 이미지 교체 전 `d27266e^` 버전으로 복원했다.
- 기존 `greet.mp4`, `greet.webm`은 바이트 변경 없이 보존했다.
- 첫 화면에 기존 인사 영상을 연결했다. 자동 재생은 무음이며 동작 줄이기 설정에서는 정지한다. 배경음은 사용자가 버튼을 눌러 켠다.
- 새 표정 초상이 풍운도령의 예전 얼굴을 덮지 않도록 했다. 풍운도령은 새 영상 제작 목록에서 제외했다.
- 새 목소리나 새 영상을 생성했다는 의미는 아니다. 별도 음성 파일은 아직 설정하지 않았다.

## 검증

- Next.js 프로덕션 빌드, 타입 검사, 린트 통과.
- 기능·카피·레이아웃 정적 검사: 1,277개 통과, 2개 건너뜀.
- 별도 기존 초상 규격 검사: 2개 통과, 3개 실패. 풍운도령 외 기존 원본의 상단 여백·잘림 문제이며, 이번 디자인 변경으로 원본 이미지가 모두 보정된 것은 아니다. 테스트를 삭제하거나 기준을 느슨하게 하지 않았다.
- 26개 경로·탭 × 320/390/1440px, 총 78개 브라우저 화면 확인. 보고서 탭은 로딩 화면을 넘겨 본문까지 확인했다. 가로 넘침과 자바스크립트 오류가 없었다. 공유는 격리된 API에서 발급한 링크로 확인했다.
- 결제 전환 동선 6개 시나리오 통과: 건너뛰기, 공감, 비공감, 데스크톱, 판매 준비 완료 모의 상태, 일시 오류 후 재시도. 실제 PG와 실제 고객 결제는 실행하지 않았다.
- 풍운도령 원본 파일 일치와 일반 환경에서 재생 시간 증가, 동작 줄이기 환경에서 정지를 확인했다.

실제 1만 명의 이용·구매 실험 결과가 아니며 결제율을 추정한 수치가 아니다. 판매자 정보 미등록 상태의 결제 차단도 그대로 유지한다.

검증 도구: `tools/verify_design_pages.py`, `tools/verify_conversion_improvements.py`, `tools/narration_hao.cjs`.
