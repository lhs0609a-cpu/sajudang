# 19 · 출시 체크리스트 — 팔기 전에 채울 것

`python tools/launch_audit.py` 가 이 문서의 코드 쪽을 자동으로 셉니다.
여기 적힌 것은 **도구가 대신 못 하는 것**입니다.

## 1. 관공서에서 받아 오는 것 (사람이 함)

| 무엇 | 어디서 | 왜 |
|---|---|---|
| 사업자등록 | 홈택스 | 없이 팔면 무등록 사업 |
| 통신판매업 신고 | 정부24 · 관할 구청 | 전자상거래법 §12. 신고번호를 화면에 적어야 함 |
| 「성신당」 상표 검색 | 특허로 kipris.or.kr | **성심당(聖心堂)과 한 글자 차이.** 제41류(교육·오락)·제45류(점술) |
| 결제대행 계약·정산계좌 | 토스페이먼츠 | 키는 이미 들어가 있음 |

★ 상표는 **이름을 알리기 전에** 봐야 합니다. 코드에서 이름을 바꾸는
것은 한 번에 되지만(84곳), 손님이 알고 난 뒤에 바꾸는 것은 값이
다릅니다. 자세한 것은 `docs/11` 맨 아래.

## 2. Vercel 에 넣을 환경변수

이 여섯이 다 차기 전에는 **결제 단추가 안 열립니다** (`lib/biz.SELLABLE`).
무료 구간은 그대로 돕니다 — 표시 의무는 판매에 붙는 것이라, 안 파는
동안 서비스를 닫을 이유가 없습니다.

```
NEXT_PUBLIC_BIZ_NAME              성신당
NEXT_PUBLIC_BIZ_OWNER             (대표자 이름)
NEXT_PUBLIC_BIZ_REG_NO            000-00-00000
NEXT_PUBLIC_BIZ_MAIL_ORDER_NO     제0000-지역-0000호
NEXT_PUBLIC_BIZ_ADDRESS           (사업장 주소)
NEXT_PUBLIC_BIZ_TEL               (연락처)

NEXT_PUBLIC_BIZ_EMAIL             (환불·문의 받을 주소)
NEXT_PUBLIC_BIZ_PRIVACY_OFFICER   (개인정보 보호책임자)
```

★ 뒤의 둘은 없어도 팔리지만, **환불 신청을 받을 데**가 없으면 분쟁이
생깁니다. 같이 넣으세요.

★ `NEXT_PUBLIC_` 이라 브라우저에 그대로 나갑니다. 이건 감출 정보가
아니라 **반드시 보여야 하는** 정보입니다. 비밀은 여기 두지 마세요.

## 3. Fly 에 넣을 환경변수

```
FUNNEL_KEY        퍼널·관리자 화면을 여는 한 벌 열쇠 (24자 이상)
TOSS_SECRET_KEY   결제 승인 (이미 넣음)
```

★ `FUNNEL_KEY` 가 없으면 퍼널·관리자가 **503 으로 닫힙니다.** 열린
쪽이 기본이면 언젠가 그대로 배포됩니다. 열쇠는 하나만 둡니다 — 둘을
따로 두면 하나만 걸어 두고 배포하는 날이 옵니다 (`keyguard.py`).

## 4. 코드 쪽 — 도구가 셉니다

```powershell
python tools/launch_audit.py    # 법정 고지 · 사업자 표시 · 열쇠 · 금지어
.\dev.ps1 engine-check          # 계산 · 분포 · 중복률
.\dev.ps1 ladder                # 값 ↔ 컷수
python tools/edge_audit.py      # 그림 가장자리
python tools/blunt_audit.py     # 뜬 말 · 팩폭
python tools/plain_audit.py     # 비유
```

`tests/test_launch.py` 여덟 검사가 이 자리를 지킵니다.

## 5. 아직 남은 것 (팔 수는 있으나 미완)

| 무엇 | 상태 | 막는가 |
|---|---|---|
| 만세력 앱 대조 20건 | 회귀 50건은 독립 계산으로 잠금. **유파 확인만 남음** | 안 막음 |
| 장면 에셋 | 9/24 (나머지는 자리표시 SVG 로 동작) | 안 막음 |
| 캐릭터 초상 | 1/20 | 안 막음 |
| 알림 채널 | `scripts/notify.py` 가 예약만 만듦 | 안 막음 |
| 결제 실거래 | 키는 있으나 **한 건도 안 통과시켜 봄** | ★ 실제로 한 번은 해야 함 |
| 얼굴 사진(면상선생) | 생체인식정보라 보류 | 안 막음 |

★ **결제는 소액으로 한 번 실제로 통과시켜 보세요.** 코드는 검사로
막았지만(`tests/test_pay_flow.py`), 승인·정산·환불은 PG 쪽 계정
설정에 걸립니다. 그건 배포본에서만 드러납니다.

★ 만세력 대조는 **팔기 전에** 하는 게 낫습니다. 손님이 다른 앱과 대
보고 다르다고 할 때, 우리가 어느 유파인지 이미 화면에 밝혀 두었지만
(`/v1/chart` 의 `divergence`), 20건을 바깥 눈으로 확인해 두면 그
말에 무게가 실립니다. `.\dev.ps1 plan` 참고.
