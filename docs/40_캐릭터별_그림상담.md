- 인코딩·도해 재생성: `python tools/build_choice_assets.py`. 새 원본만 640px WebP로 변환한다.

## 입력과 결과 연결

`GET /v1/report/choices?lens_id=...`는 선택 ID·라벨·그림 경로·형태 설명만 반환한다.
선택하지 않은 풀이 원문은 서버의 `engine/visual.py`와 `seed/extras.json`에 남는다.

기존 요청 `extras`에 `face`, `body`, `scene`을 추가했다. 예:

```json
{"face":{"shape":"round","features":{"eyes":"up","nose":"wide"}}}
{"body":{"regions":["neck","back"],"state":"pain","duration":"days","impact":"disrupt"}}
{"scene":{"lens_id":"hunjang","pick":"tired"}}
```

- 면상선생의 미구현 `photo` 입력을 `face`, 약초의원의 일반 `context` 입력을 `body`로 변경.
- 나머지 16명의 장면 질문은 기존 계산용 추가 입력을 보존하면서 `scene` 풀이를 더한다.
- 패선생의 프론트 `card` / 서버 `cards` 불일치를 `cards`로 통일.
- 모든 새 입력은 ID 허용 목록으로 검사. 다른 캐릭터의 장면·알 수 없는 부위·중복·과다 선택은 오류로 반환하고 원래 리포트는 유지.
- 얼굴형을 모르면 부위만 선택 가능. 부위도 전부 모르면 제출하지 않는다.
- 신체 부위는 3곳까지. 전반적인 컨디션은 다른 부위와 섞지 않는다.
- 선택은 화면 상태와 요청에서만 사용. 새로운 DB·브라우저 영구 저장·이미지 업로드를 추가하지 않았다.
- 관상·몸·상황의 새 풀이 컷은 무료로 확인. 기존 몽화·패선생의 풀이 이용권 범위는 유지하고, 잠긴 경우 화면에서 알린다.
- 선택 후 그림·순서·부위를 확인하고 수정 가능. 같은 상담의 탭을 오가도 현재 선택을 복원한다.
- 새 결과는 기존 출력 가드를 통과하고, 결과 바로 가기로 해당 본문을 펼칠 수 있다.

## 관상·몸 콘텐츠의 의미

관상은 **성신당의 창작 상징 도감**이다. 검증된 성격 검사나 특정 학파의 관상 분류로 표방하지 않는다.
얼굴형·눈매로 실제 성격, 도덕성, 건강, 수명, 재물 또는 미래를 판정하지 않는다.
사용자가 고른 모습과 상징적 자기 성찰 질문을 보여주고 사주 계산 부분과 구별한다.

약초의원은 사용자가 알려준 부위·상태를 정리한다. 신체 부위를 오행에 대응하여 원인을
추정하거나 약초·약물·운동을 처방하지 않는다. 심한 불편에는 의료진 확인을 먼저 안내한다.
갑작스럽고 지속되는 가슴 통증·호흡 곤란에는 의료 도움 안내를 표시한다.
이 안내의 참고 자료: [NHS 가슴 통증](https://www.nhs.uk/symptoms/chest-pain/),
[London Ambulance Service 응급 도움](https://www.londonambulance.nhs.uk/our-services/emergency-care/calling-999/).
한국 화면의 긴급 연락은 119로 표기했다. 자동 진단·응급도 점수는 없다.
