# 15 · 분석지 · 공유 · 유입 설계

> 08번 문서에는 `c5 공유카드 = PNG 저장` 한 줄만 있었습니다.
> **공유 링크도, 링크를 받고 들어온 사람이 보는 화면도 설계에 없었습니다.**
> 이 문서가 그 자리를 채웁니다.

구현 : `services/api/engine/summary.py` · `routers/share.py`
화면 : `apps/web/app/summary` (c7·c8) · `apps/web/app/s/[token]` (s1·s2)

---

## 1. 왜 필요한가

릴레이는 **집 안에서** 도는 장치입니다. 집 밖으로 나가는 길이 없으면
신규 유입은 전부 광고비로 사야 합니다.

다만 이 카테고리에서 공유는 두 번 막힙니다.

```
① 보내는 사람   "내 생년월일이 넘어가는 거 아냐?"
② 받는 사람     "사주? 그런 거 안 믿는데"
```

둘 다 풀지 못하면 공유 버튼은 눌리지 않습니다.

## 2. 분석지 (c7)

다 읽고 나서 **한 장으로** 받아보는 것. 7절로 고정합니다.

| 절 | 무엇 | 출처 |
|---|---|---|
| 여덟 글자 | 명식 · 시주 미상이면 잠금 표시 | Features.pillars |
| 저울 | 오행 막대 · 가장 약한 것 | Features.elements |
| 늘 이 순서요 | 훅 2단 그대로 | bank IGNITE→FLOW→RESULT→BLAME |
| 지금 어디에 | 대운 맵 · 순행/역행 | Features.daeun · forward |
| 누가 돕는가 | 길신 × 궁위 | sinsal.helpers |
| 뿌리 | 년주 = 조상 자리 | sinsal.ancestor |
| 필요한 것 | 용신 + 다과상 | Features.yongsin · bank TEA |

### 핵심 3줄 — 공유 카드에 박히는 것

```
① 무엇이 없는가       RESULT[약오행]
② 힘이 어디로 나가는가  FLOW[흐름]
③ 그래서 붙는 이름     NAME2[약오행][흐름]
```

### ★ 단서(caveats)를 접지 않는다

분석지 하단에 **흐린 부분을 그대로 적습니다.**

```
· 때를 몰라 세 기둥으로 셈했소
· 주도 십신이 다른 것과 개수가 같았소 (43% 가 동률)
· 가장 약한 오행이 둘이오
· 절입 전후 24시간 안에 태어나셨소
```

잘 맞는 부분만 골라 보여주면 그 순간 "맞히는 집" 이 됩니다.
공유된 화면에도 이 단서가 **같이 따라갑니다.**

## 3. 공유 (c8)

```
POST /v1/share  →  { token, path: "/s/xxxx", includes[], excludes[] }
```

### 담기는 것 / 안 담기는 것

| 담김 | 안 담김 |
|---|---|
| 여덟 글자 · 일간 · 신강약 · 흐름 | **생년월일** |
| 핵심 3줄 · 7절 본문 | **태어난 시각** |
| 신살 이름과 자리 | **태어난 고을** |
| 단서(caveats) | **보정 내역** (몇 시 → 몇 시) |
| 보낸 사람 이름(선택) | 연락처 |

보내는 사람에게 **무엇이 담기는지 먼저 보여준 뒤** 링크를 만듭니다.
몰래 담지 않습니다. `reveal="light"` 로 하면 여덟 글자도 빼고
일간과 3줄만 나갑니다.

링크는 **90일 뒤 스스로 닫힙니다.**

### 계측

`POST /v1/share/{token}/open` 하나뿐입니다. 바이럴이 실제로 도는지
보는 유일한 숫자입니다. 누가 열었는지는 남기지 않습니다.

## 4. ★ 유입 화면 (s1·s2) — 순서가 전부

링크를 받고 들어온 사람은 **우리를 모르고, 사주를 안 믿을 수도** 있습니다.
순서를 지킵니다.

```
① 누가 보냈는지 먼저 밝힌다
     "○○님이 이 종이를 보내셨소. 광고가 아니라, 아는 사람이 건넨 것이오."
     이름이 없으면 → "누가 보냈는지는 적히지 않았소."

② 친구의 것을 보여준다
     자랑이 아니라 근거가 붙은 글로. 여덟 글자 + 핵심 3줄 + 신살.
     "생년월일과 태어난 고을은 이 링크에 담기지 않았소."

③ 의심을 우리가 먼저 꺼낸다        ← 여기가 이 화면의 본체
④ 그제야 권한다. 값은 묻지 않는다.
```

### ③ 의심 목록 — 여섯 가지

전부 **코드로 확인 가능한 사실만** 적습니다.

| 의심 | 우리가 내놓는 것 |
|---|---|
| 사주를 믿냐면 | "맞히는 집이 아니라 근거 대는 집이오" — 근거를 화면에 전부 적음 |
| 다들 하는 만세력 아니냐면 | 절기를 **날짜가 아니라 시각까지** 셈함 |
| 1954~1961년생이면 | 그 시절 표준시 **127.5도** · 서머타임 12구간 되돌림 |
| 시각을 모르면 | 시주를 **세우지 않음.** 12시로 채우지 않음 |
| 적중률 숫자가 없어 이상하면 | 응답 **100건** 전에는 공감률을 안 띄움 |
| 결국 돈 아니냐면 | 무료 구간까지 값을 안 물음 · 하루 2건 · 세션 2명 |

### 쓰지 않는 말

```
적중률 · 과학적 · 통계학 · 입증 · 보장
```

의심을 이기려고 거짓을 보태면 **그 자리에서 끝납니다.**
`tests/test_sinsal_share.py::test_referral_landing_makes_no_accuracy_claim`
이 이 화면의 문구를 감시합니다.

## 5. 화면 대장 갱신

08번 문서의 27화면에서 다음이 늘었습니다.

```
c7 분석지 · c8 공유          → /summary
s1 받은 분석지 · s2 의심 풀기  → /s/{token}
```

`tools/screen_graph.py` 의 `SCREEN_MAP` 이 정본입니다.
`/s/[token]` 은 바깥에서 링크로 들어오므로 **고아 화면 예외**로 둡니다.

```bash
python tools/screen_graph.py    # 고아 0 · 막다른 0 · 죽은 버튼 0
```

## 6. 아직 안 한 것

- 공유 카드 **이미지(PNG) 생성** — 지금은 링크만. `cardbg` 에셋과
  html2canvas 가 붙어야 SNS 썸네일이 생깁니다. (docs/10 §5)
- **OG 태그** — 카톡·트위터에서 미리보기가 안 뜹니다. `/s/[token]` 에
  `generateMetadata` 로 og:image·og:title 을 붙여야 합니다. 지금은
  클라이언트 렌더라 크롤러가 내용을 못 읽습니다.
- 추천인 보상 — 설계하지 않았습니다. 보상을 붙이면 브레이크(하루 2건 ·
  세션 2명)와 충돌하므로, 붙일 거면 그 충돌부터 정리해야 합니다.
