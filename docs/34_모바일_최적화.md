# 모바일 읽기 화면 최적화 · 2026-09-09

`styles/mobile.css`에서 767px 이하의 화면 간격과 타이포그래피를 별도로 정한다. 첫 화면의 표지 여백과 제목 크기를 줄여 320×568에서도 무료 해석 버튼 전체가 보이게 했다. 본문·설명 글자의 크기와 행간을 조정하고 긴 카드의 안쪽 여백, 장면 이미지 높이, 페이지 머리말 간격을 줄였다.

버튼과 펼치기 영역은 최소 높이 44px, 입력 글자는 최소 16px이다. 생년월일의 세 칸은 작은 화면에서도 줄어들 수 있다. 탭은 필요하면 다음 줄로 이어지며 터치 환경에서는 호버 시 버튼이 움직이지 않는다. `viewport-fit=cover`와 safe-area 여백으로 노치·홈바 영역을 고려했다. 확대를 제한하지 않는다.

풍운도령의 초상·인사 영상, 음성 및 결제 동작은 변경하지 않았다. 이번 변경은 이미지 원본의 잘림 보정과 별개다.

검증 도구 `tools/verify_mobile_pages.py`는 26개 경로·탭을 320×568, 360×740, 390×844, 430×932의 터치 모바일 환경으로 연다. 본문 로딩, 가로 넘침, 버튼 높이, 입력 글자 크기와 첫 버튼 위치를 확인한다. 별도로 가로 844×390, 태블릿 744×1133, 데스크톱 1440×900에서 진입·입력 화면과 생년 입력을 확인한다. 검증은 브라우저 에뮬레이션이며 실물 iPhone·Android 기기 시험은 아니다.
