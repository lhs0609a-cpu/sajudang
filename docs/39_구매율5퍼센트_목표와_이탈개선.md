# 구매율 5% 목표와 이탈 개선 — 2026-09-09

## 목표와 실제 제약

목표는 신규 진입 브라우저 10,000개당 7일 이내 서버 승인 구매 브라우저 500개다. 실제 사람 수와 익명 브라우저 수는 다르며, 동일 구매자의 여러 기기나 브라우저는 연결하지 않는다. 전환 확률을 5%가 나오도록 조정한 시뮬레이션은 개선의 증거가 아니므로 만들지 않았다.

현재 판매자 정보 미완료로 운영의 정상 결제 UI가 차단된다. 사용자에게 상호·대표자·사업자등록번호·통신판매업신고번호·사업장 주소·고객센터 전화번호를 요청했다. 실제 정보를 받기 전에는 임의값으로 판매 준비 완료 처리하지 않는다. 이 차단이 유지되는 동안 정상 UI의 실제 구매율 목표는 달성할 수 없다.

## 적용한 변경

1. 첫 해석의 긴 누적 문단: 지금 읽는 마디를 열고 이전 마디는 접는다. 답한 문단과 응답은 다시 펼쳐 읽을 수 있다. 다음 마디에 초점과 스크롤이 이동하며, 새로고침 복원과 부정·중립 응답을 유지한다. 응답 건너뛰기는 추가하지 않았다.
2. 끝나지 않는 연결 대기: 일반 API의 응답·본문 읽기를 20초로 제한한다. 실패 시 입력을 남기고 수동 재시도 경로로 돌아온다. 결제 승인·구독 등 `/v1/pay` 변경 요청에는 이 자동 중단을 적용하지 않는다. 상품 목록·미리보기 읽기만 예외로 제한한다. 판매 가능 상태 조회는 12초 후 일시 장애와 재확인 버튼으로 전환한다.
3. 상품 미리보기 실패 후 복구 불가: 미리보기의 오류와 재시도를 결제 조건 요청과 분리한다. 재시도는 실제 `/v1/pay/peek`를 다시 호출하고, 결제 주문을 새로 만들기 위한 재시도로 오인하지 않는다.
4. 새로고침 시 상품 선택 유실: 같은 탭에서 사용자가 직접 고른 상품을 명식·해석자·고민·성향별로 복원한다. 처음 방문한 사람에게 상품을 대신 고르지 않는다. 금액과 주문은 다시 서버에서 확인한다.
5. 상품을 누를 이유와 결제 위치가 불분명함: 상품 버튼에 본문·결제 조건을 확인하는 동작을 명시한다. 전체 분량에 무료 내용이 포함됨을 표시하고, 선택한 상품 가격·일회성/정기 결제를 보여주는 결제 조건 이동 링크를 추가한다. 실제 결제는 금액·환불 조건을 확인한 뒤 기존 결제 버튼을 눌러야만 시작한다.
6. 목표 구매율과 순차 동선 집계 혼동: 관리자에 5% 목표, 7일 관찰 완료 분모, 서버 승인 고유 구매 브라우저, 실제 전환, 현재 집단에서 목표까지 필요한 구매 수를 표시한다. 중간 화면 이벤트가 누락되어도 진입과 서버 승인이 있으면 목표 집계에 포함한다. 순차 동선 표는 순서를 요구하는 기존 집계를 유지한다. 미성숙 방문, 중복 승인, 클라이언트 완료 이벤트로 목표 숫자를 부풀리지 않는다.

## 5%를 판단하는 방법

판매 가능 상태와 실제 PG 연결이 준비된 뒤, 관리자에서 7일 관찰을 마친 집단의 서버 승인 비율을 확인한다. 5% 이상인 한 번의 관찰만으로 이후 유입에도 같은 구매율이 보장되는 것은 아니다. 유입 경로·기기별 성과, 무료 해석 부정 응답, 가격 화면 도달, PG 진입 실패, 승인 실패·환불을 함께 살핀다. 현재 변경으로 몇 퍼센트가 올랐다고 주장할 실제 고객 데이터는 아직 없다.

## 미해결 범위

판매자 설정은 실제 정보가 필요하다. 기존 초상화의 원본 상단 잘림·정렬 검사 실패는 이 변경으로 해결되지 않는다. 엔진의 합성 사례 통과는 공감도나 구매 의사의 검증을 대신하지 않는다. 음력 생일은 현재 양력 변환 입력이 필요하며, 이 부분의 지원 범위도 그대로다.

## 검증

- Next.js 운영 빌드 통과.
- 집계·전환 집단 테스트 26개와 결제 화면·판매 상태 계약 검사 12개 통과.
- 브라우저 8개 흐름과 대기 제한 복구 2개 흐름 통과. 긍정·부정·중립, 새로고침, 미리보기 503 후 재시도, 판매 상태 복구를 포함한다. 응답 없음 요청의 대기 제한은 실제 20초/12초 타이머로 검증했다.
- 320×568, 360×740, 390×844, 430×932에서 26개 경로·탭씩 총 104개 검사 통과. 가로 넘침, 입력 글자 16px 이상, 버튼 높이 44px 이상, 첫 화면 행동 버튼 노출을 확인했다. 실제 사람의 이해도나 미적 선호도 테스트가 아니다.
- 테스트 API는 로컬 저장소로 격리하고 PG 호출과 운영 분석 이벤트를 제외했다.
